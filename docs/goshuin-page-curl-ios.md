# 御朱印帳のiOSページカール確認

御朱印帳の開いた見開きは、iOS開発ビルドでは `UIPageViewController` の `pageCurl` を使用します。右側に取得済みの御朱印、左側とめくった紙の裏面に無地の和紙を表示します。未取得ページには御朱印画像を載せません。ページ番号と詳細表示は既存のReact Native画面に連動します。

## 開発ビルド

Expo GoにはこのローカルiOSモジュールが入らないため、`development` プロファイルの開発ビルドを使います。既存の `eas.json` に同プロファイルがあります。iOSビルド可能な環境で `eas build --platform ios --profile development` を実行し、端末へインストールしてください。Metroは `npx expo start --dev-client --port 8083` で起動できます。

## 確認箇所

1. 御朱印帳の表紙をタップすると、外側のカード枠がない見開きが表示される。
2. 右ページを左へゆっくりドラッグすると、iOSのページカールが指に追従し、裏面に無地の和紙が見える。
3. 指を途中で戻して離すと、元のページに戻り、ページ番号は変わらない。
4. 最後までめくると、次の御朱印ページが下から現れ、ページ番号が1つ進む。
5. 未取得ページには御朱印画像が表示されず、取得後はそのページに画像が追加される。
6. 左右の矢印と「このご縁をみる」からの詳細表示が動作する。

WebとExpo Goは既存のReact Native描画に切り替わります。iOS純正の動きは開発ビルドで確認してください。
