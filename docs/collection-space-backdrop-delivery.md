# コレクション360°背景の制作記録

生成: built-in image_gen。既存の `assets/backgrounds/opening-cycle/12-1930-blue-hour.webp` を目視で参照し、和紙・水彩の藍紫、落ち着いた緑、ごく小さい暖色灯を合わせた。

生成プロンプトの仕様: 単一の12:5の360°連続パノラマ。夕暮れから夜の神社参道、森林、遠い鳥居・屋根、石道、霧と山の奥行き。中央27〜73%は暗く低コントラストで情報を抑え、灯りは小さく疎らに。上下端は #1B1426。左右は連続する森と霧で閉じる。人物・キャラクター・動物・文字・看板・印・ロゴ・UI・大きな光球は禁止。分割図やコラージュにしない。

生成画像1942×809pxを6656×2560pxへバイキュービック拡大し、左右512pxの景色をクロスフェードして6144×2560pxの連続パノラマにした。上下280pxを背景色へフェード、中央帯を追加で控えめに調整した後、1536px幅で4等分。生成時点のネイティブ解像度は納品寸法より小さい。

再生成後の整形・検査は `collection-space-backdrop-build.cjs`。一時的に作成した6144×2560のマスターPNGから全タイルを切り出す。WebP quality 82、アルファなし。納品画像を再デコードしてからプレビュー・検査記録を作成する。

- `collection-space-backdrop-preview.png`: 1→2→3→4を横連結、2304×960px。継ぎ目の位置は25%、50%、75%。
- `collection-space-backdrop-wrap-preview.png`: 4の右端→1の左端。中央が一周の接続部分。
- `collection-space-backdrop-validation.json`: 形式・寸法・容量・アルファ、各接続の画素差。

登録は `collectionSpaceBackdrop.ts` の1→4順のみ変更。3D表示コードは変更していない。実機での3D表示は未検証。
