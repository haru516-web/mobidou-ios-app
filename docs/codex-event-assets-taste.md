# Codex 向け イベント画像のテイスト改訂（「レトロ」ではなく、昭和旧車の迫力と平成のキラキラ）

`docs/codex-event-assets.md` で作った画像（`assets/event-toki/`）は、落ち着いた「レトロな工芸品」の仕上がりになっている。狙いはそれではなく、**昭和旧車のギラついた迫力**と**平成のキラキラ**を、ガンガンに前面へ出すこと。ここでは、その方向に描き直すための指示だけを書く。形式・寸法・ファイル名・禁止事項は前回の文書のまま。

## 目指す空気

| 章 | キーワード | 画面の印象 |
|---|---|---|
| 昭和（1〜5） | 旧車ショー、クロームの照り、キャンディ塗装のツートン、白フチの太いタイヤ、大きな丸目/角目のライト、夜のナトリウム灯（オレンジの街灯）、ネオンの看板、ガソリンスタンドの電飾 | **ギラギラ・重厚・コントラスト強め**。艶と反射が主役。古びた質感ではなく、**磨き上げられた愛車**。 |
| 平成（6〜8） | キラキラ、ラメ、ラインストーン、ホログラム、シール手帳、パステルのピンクと水色、蛍光色、グラデーション、星・ハート・リボンのきらめき、デコ電（デコレーションした携帯） | **ポップ・ツヤツヤ・盛る**。余白が少なくなるほど飾る。 |

「古い」「色あせた」「すすけた」「かすれた」「渋い」「落ち着いた」は**使わない**。傷・サビ・塗装のかすれも描かない。

## 描き方の指示（共通）

- **彩度と明度を上げる。** 前回の画像は全体にくすんでいたので、色は一段鮮やかに。コントラストは強く。
- **光を描く。** 昭和は金属の反射（クロームのハイライト、ボディの映り込み）と街灯・ネオンの光。平成はラメの粒、ホログラムの虹色の反射、星形のきらめき。
- **構図は大きく、斜め。** 主役（車・携帯など）を画面いっぱいに、3/4ビューや見上げの角度で、迫力をつける。静止画のカタログ写真のようにしない。
- **和の要素（社・鳥居・墨書き・朱印）は残す。** もび道の世界観の中にあることは変えない。ただし和紙の落ち着きより、**派手な背景と墨の太い筆文字**のコントラストを優先する。
- 実在の車種・メーカー・エンブレム・ロゴ・型番・通信会社・商品名・キャラクターは**描かない**。形は「昭和の旧車っぽい」オリジナルにする（例：箱型の四角いボディ、丸目四灯、長いボンネット、太いクロームバンパー、ワイドなタイヤ）。
- **暴走族・不良の描写はしない**（特攻服・旗・鉄パイプ・暴走・ケンカ・危険運転の表現）。旧車ショー、愛車自慢、ドライブの楽しさ、として派手にする。ここは審査（年齢区分）に関わるので守る。
- 「プリクラ」「たまごっち」など実在の商標名にあたるものは描かない・書かない（「シール写真」「育成ゲーム」の雰囲気までにとどめる）。
- 画像内に文字は描かない（御朱印の墨書きだけ可。前回どおり）。

## 項目ごとの変更

### E. ミニチュアキーホルダー 8点（既存 `keychains/` を描き直す）

- **昭和の車3点（showa-shoutengai / showa-toge / showa-drivein）:** 磨き上げたダイキャスト。キャンディ塗装（深いメタリックの赤・青・緑のツートン）、ミラーのようなクロームのバンパー・モール・ホイール、白フチの太いタイヤ。強いハイライトと映り込み。3車は**シルエットから別の車に見える**こと（丸みのあるセダン／四角いクーペ／長いボンネットのスポーツカー。前回はクーペがセダンに見えた）。
- **昭和の電気製品2点（showa-sento 黒電話 / showa-record ラジカセ）:** 艶のある黒とクローム、金属のメーター、赤や緑のランプの発光。ラジカセはイコライザーのランプを光らせる。
- **平成3点（heisei-park ガラケー / heisei-pager ポケベル / heisei-century デジカメ）:** デコ電のように**ラインストーン・ラメ・ホログラムシール・リボン・星のチャーム**で盛る。ボディはパステルのピンク/水色/ラベンダー、虹色に光る反射。ストラップ（ビーズ・マスコット・ハートや星のチャーム）を何本もつける。画面や液晶は光らせる。
- 金具・チェーン・紐・木札の作りは前回のまま。木札の墨絵は残す。**紐の色は章ごとに変える**: 昭和は藍×白、平成はピンク×水色。

### F. 御朱印 8点（既存 `goshuin/` を描き直す）

- **昭和5点:** 夕焼けのオレンジ一色ではなく、**夜の峠・ナトリウム灯・ネオン・ガソリンスタンドの電飾**など、シーンごとに色と光を変える（商店街の看板ネオン／峠の夜景とテールランプの光跡／ドライブインの電飾／銭湯の湯気と煙突／レコード坂のネオン）。車は画面の大きな主役、クロームが光る。
- **平成3点:** **キラキラの背景**。パステルのグラデーション、ラメ、星・ハート・リボンの散りばめ、ホログラムの虹。ガラケー・ポケベル・デジカメを大きく、装飾つきで。墨書きの背景に**金や虹色の縁取り**を足し、文字がキラキラの中でも読めるようにする。
- 朱印の印影はそのまま（ミニチュアの簡略図）。左下の「もび」落款も維持。墨書きは**太く力強い筆**で。

### B. イベント専用マップ（既存 `map.webp`）

- 下半分（昭和）は**夜の街道**（街灯のオレンジ、ネオン、ガソリンスタンドの電飾、峠の連続カーブ）、上半分（平成）は**明るいパステルの空と水辺、キラキラの光**にして、**道を進むほど昭和の夜から平成の昼のキラキラへ**グラデーションで移る絵図にする。
