## いちばん大事な方針: 「レトロ」にしない。当時の新品として描く

アイテムは**懐かしいもの、古いものとして描かない**。それぞれの時代に**発売されたばかりの最新・最先端のもの**として、新品のピカピカの状態で、その時代のデザインの空気を最大限に出して描く。見る人が「懐かしい」と感じるより先に、「当時、これが最先端でかっこよかった/かわいかった」と伝わるようにする。

- **新品であること:** 傷・汚れ・色あせ・サビ・くすみ・フィルムの粒子・セピア・退色は描かない。塗装も金属もガラスも、ショールームから出したばかりの状態。
- **当時らしさを強く出す:** その時代に流行ったデザインの特徴（形、素材、色、装飾）を、ためらわずに強調する。控えめにしない。
- **「昔を振り返る」演出にしない:** ノスタルジックな色調、古びた写真風、昔のカタログ風の色褪せ、「昭和レトロ」「平成レトロ」と呼ばれるような落ち着いた配色は避ける。**その時代の最盛期の、派手で明るい配色**にする。
- 背景やシーンも同じ。商店街・峠・ディスコ・駅前・渋谷系のファッションビルなどは、**その時代の真っ只中の賑わい**として描く。
