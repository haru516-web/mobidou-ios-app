# Codex向け: UIスモークテスト依頼

コード整理（未使用コード削除・`App.tsx`から設定画面を `SettingsModal.tsx` へ分割）の後で、見た目と導線が壊れていないかを確認する。**コードは変更せず、結果を報告するだけ**にする。

## 準備

```powershell
cd D:\mobby\mobidou
npm run web        # http://localhost:8083
```

初回は「まずは体験してみる」から体験モードに入る。ブラウザの開発者ツールでビューポートを切り替えて確認する。

## 確認する画面（各サイズ）

1. オープニング → 体験開始
2. ホーム（カード2枚、モビー、歩数リング、下部ナビ）
3. ホームのカード編集ポップアップ（設定 →「ホームのカードを編集」、またはカード長押し）
4. 巡礼（ルート選択、地図）
5. 御朱印帳（表紙、ページ、目次）
6. コレクション
7. おみくじ
8. **設定**（分割した画面。上から下まで全項目）
   - アカウント管理 → 開いて戻れる
   - 歩数のつながり（Webでは「iPhoneで利用」の案内）
   - ホームのカードを編集 → 設定が閉じてカード編集が開く
   - ふれあいの振動のスイッチ
   - 体験モードの切り替え → ホームに戻る
   - 「プライバシーとデータ」「もび道について」→ 文章が読める、「とじる」で閉じる
9. プレゼント箱・友達・お知らせ（ソーシャル画面。空の状態も）

## 合否の基準

- 縦スクロールしなくても収まる画面（設定・コレクションギャラリー以外）で、内容やボタンが**切れていない・はみ出していない**。
- 文字が画像やボタンの外にはみ出していない。
- 各ボタンが押せて、意図した画面へ移動し、戻れる。
- ブラウザの console にエラーが出ていない。

## 報告形式

サイズ×画面の表で「OK / NG」を書き、NGは画面名・サイズ・症状・スクリーンショットのパスを付ける。修正はしない。
