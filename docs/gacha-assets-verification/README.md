# ガチャ素材の確認記録

確認日: 2026-09-30。ブランチ: `codex/v3-followups`。

## ピクセルと容量

`pixel-audit.json` は最終WebPをPillowで開き直した結果。7点の寸法が依頼と一致し、すべて400,000 bytes未満。背景以外の6点はRGBAで、四隅のアルファ値はすべて0。光・影の四辺も透明で、紐だけは仕様どおり上端まで続く。

`stage-bg.webp` は依頼文書の背景例外として全面不透明。RGBAで書き出したが、一様なアルファ面をWebPエンコーダーが省略するためデコード時はRGB。RGBAとして読むと全画素のアルファ値は255。7点すべてが透過画像という判定にはしていない。

## 目視

- `box-closed.webp`: 同じ880×1280キャンバスで本体の上に前板をアルファ合成。前板が本体の開口全体を覆い、輪郭に隙間やずれがない閉じた箱として確認。
- `box-overlay-review.webp`: 漆塗りの箱2枚を重ねた閉じた箱を確認。`box-parts-review.webp` は本体・前板・合成結果を並べた比較画像。両素材のアルファ外接矩形は `(50, 75, 830, 1205)` で一致。
- `all-assets-review.webp`: 明るい生成りと暗い藍灰の背景に各素材を重ね、透過部に市松模様が焼き込まれていないことを確認。絵に文字や数字はない。前板中央のロゴはユーザーの追加指定で、既存 `assets/mobidou-opening-emblem.webp` を入力に使用。
- 箱と紐に外部の接地影はない。影は独立した `box-shadow.webp`。本体内側の奥行きの陰影と背景の建築物の陰影は絵の一部。
- 背景は夜明け前の縁側、左右の障子、遠くの灯りがあり、中央下に空いた床、上部中央に紐用の余白がある。

## 漆塗りへの差し替え

同日の追加依頼に従い、箱2点を飴色〜黒褐色の古風な漆塗りへ差し替えた。前板中央にはアプリロゴの透明版を画像編集の挿入入力として使用。ロゴ原本のピクセルを直接合成したものではなく、image_genによる編集出力である。鳥居・モビー・輪・巻き雲、朱・黒・金の構成を原本と見比べて目視確認した。

追加指定により、初回依頼の明るい桐色と中央の抽象的な朱の紋を、漆仕上げとアプリロゴに変更。その他の寸法・透過・前板構造・容量の条件は維持。親担当が最終WebPを再検査し、箱以外5素材とロゴ原本のSHA256が作業前と一致することも確認した。
