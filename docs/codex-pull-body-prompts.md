# Codex prompt: 引っ張り用ボディ画像の足元の市松残り

対象は **病みモビー (`yami`)** と **もびち (`mobichi`)** の2体です。
ほっぺを引っ張ったとき、足の下に灰色/白の市松模様(偽の透過)が見えます。
原因は `assets/mobies/pull/<name>-body-clean.webp` の足元に市松が焼き込まれていることで、
コードでは消しきれませんでした(`scripts/bleed-pull-bodies.cjs` で他の7体は対処済み)。

## 共通ルール

- キャンバスは 1254×1254 のまま、キャラの位置・大きさ・形は一切変えない。
- 変更するのは足元(下から約20%)の、キャラの外側にある市松だけ。毛・服・小物には触れない。
- 出力は **アルファ付き** で、背景は本物の透明(市松の絵ではない)。
- 完了後、`node scripts/bleed-pull-bodies.cjs` → `node scripts/build-pull-gl-textures.cjs` の順で実行する
  (元画像から作り直すので、先に `git checkout -- assets/mobies/pull/<name>-body-clean.webp` で
  Codexが作った画像を差し替えてから、`bleed` スクリプトが二重に処理しないよう注意する)。

## プロンプト(画像編集)

```text
添付は、ぬいぐるみキャラクターの全身画像 <yami-body-clean.webp / mobichi-body-clean.webp> です。
足の下や足の間に、透過を表す灰色と白の市松模様が絵として残っています。
これを取り除き、本物の透明(アルファ0)にしてください。

守ること:
- キャラクター本体(毛、服、ベルト、足の裏の毛先など)は1ピクセルも変えない。
- 画像サイズ 1254x1254、キャラの位置と大きさはそのまま。
- 足の下の影は不要。影も市松と一緒に透明にしてよい。
- 足の外側の輪郭は、毛の細かい先端まで自然に残し、白いフチや市松の名残を付けない。
- 出力はPNG(アルファ付き)。背景は完全な透明。

出力ファイル名: yami-body-clean.png / mobichi-body-clean.png
```

## 確認方法(Codexが自分でやる)

- 濃い色(例: `#8a2f27`)の背景に出力を重ねて、足元に灰色や白のチェック柄が残っていないこと。
- 元画像と重ねて差分を取り、足元の外側以外に変化がないこと。
- 引っ張り画面(Web)で該当キャラを引っ張り、足の周りに白い縁が出ないこと。
