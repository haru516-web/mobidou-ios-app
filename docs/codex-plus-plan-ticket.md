# プラスプラン用の金色の札（Codex依頼）

## 目的

ガチャのショップに並ぶ「プラスプラン」の商品画像は、いまミニチュアキーホルダー引換券の画像をそのまま使っている（`src/data/gachaUiArt.ts` の `SHOP_PRODUCT_ART.plus`）。
引換券と区別がつかないので、**プラスプラン専用の札を、引換券の色違い（金）として1枚作る。**

## 素材

| ファイル | サイズ | 内容 |
|---|---|---|
| `assets/ui-round3/tickets/ticket-plus-plan-gold-v1.webp` | 1023×1535（引換券と同じ） | プラスプラン用の札。透明背景 |

## 参照（必ず見る）

- `assets/ui-round3/tickets/ticket-keychain-drop-v2.webp` … いまの引換券。**形・縁・穴・点線・和紙の質感・文字の配置・草と道の絵は、これと同じにする。**
- ガチャの木札の画像（`assets/ui-round6/tickets/ticket-gacha-tag-v1.webp`）と並んでも浮かない作風にする。

## 変えるところ

1. **色**: 引換券の青緑（深い緑青）の部分を、**金**にする。
   - 面の色は落ち着いた金（`#B8923F` 付近）。墨の掠れや擦れの質感は引換券と同じように残す。べったりした黄色や、ギラギラした金属光沢は避ける（和紙の上に金泥・金箔を置いたような見え方）。
   - 縁の細い金線は、少し明るい金（`#D8B867` 付近）。
   - 左上の銅色の丸い印と、上の穴の金具は、金の面と合う色に（銅のままでも、金寄りでも可。金の面と馴染むほう）。
   - 紙の生成り色（地）は引換券と同じ。
2. **文字**（引換券の文字配置をそのまま使い、文言だけ差し替える）:
   - 上の小さい2行: 「MOBIDOU」「旅の授与札」はそのまま。
   - 大きい3行 → 大きい1行: 「プラスプラン」
   - その下に小さく1行: 「ミニチュアが必ず授かる」
   - 一番下の小さい文: 「ご縁を、いつも手元に」
   - 文字の色は引換券と同じ濃い緑青ではなく、**金に馴染む濃い茶〜焦げ茶**（`#4A3318` 付近）。読みやすさを優先する。
3. **左上の丸い印の絵**: いまはキーホルダー。**プラスの意味が分かる印**（例: 木札とキーホルダーが重なった図、または小さな「＋」を添える）に。細かくしすぎず、縮小しても分かる大きさで。

## 変えないところ

- 札の輪郭、上の穴、下の点線と切り欠き、草と道のシルエット、右側の塗りの形（色だけ金に）。
- 画像サイズと余白（引換券と同じ位置に収める）。

## 共通ルール

- 背景は完全な透明（アルファ）。市松模様や透けた背景の焼き込みは禁止。
- ファイル形式は WebP。引換券（約530KB）を超えないこと。
- 文字は崩さない。日本語が読めること。誤字・欠字は不可。
- 生成に使ったプロンプトは `docs/gacha-assets-prompts.md` に追記する。
- コード（`src/`、`App.tsx`）は変更しない。素材と記録だけ。差し替えはこちらで行う。

## 確認

- アルファ付きで、四隅のピクセルが完全に透明であること（`scripts/audit-image-assets.cjs` の手順を使う）。
- 暗い色（`#302D25`）と明るい色（`#C79A62`）の両方の上に重ねて目視し、輪郭と文字が読めること。
- 引換券と並べて、色以外の形が一致していること（縮小して重ねて確認）。
- 完了したらファイルのサイズをコミットメッセージに書く。
