# Codex 向け UI アセット生成プロンプト

## 作業ルール(Codex に最初に渡す)

- 作業ワークツリー: `D:/mobby/mobidou-assets`(ブランチ `codex/ui-washi-assets`)
- **コードは触らない**。追加してよいのは `assets/ui-washi/`、`assets/pop-buttons/`、`assets/mobies/actions/<mobby-id>/` 配下の画像だけ。
- 生成は PNG(透過)で出し、既存パイプラインと同じく WebP(品質90前後、アルファ維持)に変換して置く。PNG は残さない。
- 命名は小文字ケバブケース。各アセットの寸法・透過・「中身を空にする」指定を厳守する。
- 完了後、ファイル一覧と各寸法を `assets/ui-washi/MANIFEST.md` に書く。
- 生成後は全画像を目視し、下の「共通の合格条件」を確認する。

## 共通スタイル指示(全プロンプトの冒頭に付ける)

```
アプリ「もびどう」の UI 部品。既存の和紙・御朱印・巡礼の世界観に合わせる。
- 素材は実物の和紙、麻布、木札、墨、朱。フラットな単色塗りと機械的な角丸矩形は禁止。
- 縁は手でちぎった耳(不揃いで繊維が毛羽立つ)か、筆で引いたかすれ。直線・正円の縁を使わない。
- 光源は左上の柔らかい自然光。影は「物の実際の輪郭に沿った」薄い接地影のみを右下に落とす。
  箱型・均一ぼかしのドロップシャドウは禁止。影を入れる指定がある物だけ焼き込み、それ以外は影なし。
- 配色は生成り、淡い墨、朱、藍、若草の低彩度。既存背景(assets/backgrounds)と並べて浮かない明度。
- 文字・数字・ロゴ・透かし・キャラクターを絵の中に描かない(指定があるものを除く)。
- 背景は完全透過。縁のアンチエイリアスに白フチや黒フチを出さない。
```

## 共通の合格条件

1. 透過背景で、縁に白/黒のフリンジがない。
2. 文字・数字・キャラクターが混入していない(指定物を除く)。
3. 中身を空にする指定の部品は、中央の 60% が無地の和紙面で、文字を載せても読める(明度の差が小さい)。
4. 角丸矩形・直線的な縁・均一ドロップシャドウがない。
5. 同じセット内で光の向き、紙の色味、繊維の密度が揃っている。

## G. モビ坊の礼拝スプライト(二礼二拍手一礼を作り直し)

対象: `assets/mobies/actions/mobibou/` の `mobibou-rei-01..08.webp` と `mobibou-hakushu-01..08.webp`(ストーリーボードも更新)。
**今回は mobibou(モビ坊)だけ。** 他キャラは確認後に別途依頼する。
進め方: シートを2枚生成(rei、hakushu)→ `scripts/pack-prayer-sheets.cjs` の方式で8コマに切り出し → 検証。

```
既存のシートとフレームを開き、以下の不自然さの原因(足元のブレ、体の大きさの変化、
動きの唐突さ)を確認してから作り直す。キャラの造形は既存ファイルと完全に同じ。

【シートの仕様(後で等間隔に切り出すため厳守)】
- 4列×2行の8コマ。各セルは同寸の正方形で、シート全体は等間隔のグリッド。透過背景。
- キャラは自分のセルの中に完全に収める。手・頭・影・効果線が、
  セルの境界線から最低 8% の余白を残す。隣のセルにはみ出さない、隣のコマの一部が入り込まない。
- 前後のコマの動きの残像、ゴースト、ブラー、動きの軌跡線を描かない。1コマ=1つの静止ポーズ。
- 全コマでキャラの大きさを同じにし、足元(接地点)を各セル内の同じ座標に固定する。
- セル間に区切り線、番号、文字、枠を描かない。

rei(お辞儀)8枚: 01 直立で構える → 02 息を吸う予備動作(わずかに伸びる) → 03 傾き始め
→ 04 深いお辞儀の最深点 → 05 最深点で静止(04と同じ、ごく僅かに沈む) → 06 戻り始め
→ 07 戻りきる手前で少しオーバーシュート → 08 直立に落ち着く。
hakushu(拍手)8枚: 01 手を胸の前で開く → 02 手を離して構え → 03 打ち合わせ寸前
→ 04 打ち合わせの瞬間(体が僅かに縮む) → 05 反動で腕が広がる → 06 二度目の打ち合わせ寸前
→ 07 二度目の瞬間(縮む) → 08 手を合わせて祈る静止ポーズ。
```

切り出し後の検証(Codex が実施): 各コマの縁 4px 以内に不透明画素がないこと、隣のコマの断片が混入していないこと、8コマの足元位置とキャラ高さのばらつきが 2% 以内であること。

補足: 全体の再生順は `src/data/mobibouActionFrames.ts` で組む(礼→礼→拍手→拍手→礼)。フレームの並べ方や時間配分はコード側(こちら)で調整する。
