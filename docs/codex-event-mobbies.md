## 共通の作り（既存のモビーを崩さない）

**最も基本の（ノーマルな）モビー**: `assets/mobies/reference/normal-mobby.webp`（1024×1024。背景つきの参考画像で、出力の背景は透過にする）。四角っぽい毛玉の体、短い手足、大きな目（クリーム色の円盤に黒い瞳と白いハイライト）とカメラのレンズの目、胸の十字キーと丸いボタン2つ、という**元の姿の基準**。新しいモビーは、これを土台に服や髪を足す。

衣装・質感・光の参考（実際に見て、絵柄・質感・光・構図をそろえる）: `assets/mobies/mobibou.webp`、`assets/mobies/ojimobby.webp`、`assets/mobies/babumoby.webp`、`assets/mobies/dogmobby.webp`。

守る特徴（ぜんぶのモビーに共通）:
- **体:** ノーマルなモビーの、四角っぽく丸みのある、ぬいぐるみのような毛足のあるずんぐりした体。短い手足（体の形と比率はノーマルに合わせる）。フェルト・毛糸・革などの手芸素材の質感（CGっぽいツルツルにしない）。
- **顔:** 片目は大きな目（クリーム色の円盤に黒い瞳とハイライト）、もう片目は**カメラのレンズ**（黒い筒に緑の反射）。この左右の組み合わせは変えない。
- **胸:** ゲームパッド（十字キーと丸いボタン2つ）が胸にある。位置と大きさも既存と同じ。
- **衣装・小物:** そのモビーの個性として、体に**着せる・付ける**形で足す（帽子、チョッキ、リュック、スカーフなど、既存のモビーも同じやり方）。体の形・顔・ゲームパッドを隠さない。
- **見た目の向き:** 正面向き、全身が見える、足が地面についている。ほぼ左右対称の立ち姿（片手を軽く上げるなど、小さな動きは可）。
- **ライティング:** やわらかいスタジオ光。影は小さく、地面の影は描かない。

出力の形式（既存と同じ）:
- 1254×1254、WebP（品質90）、**背景は透過**、体のまわりに余白を残す（体の幅は画面の約75〜80%）。
- 画像内に文字は描かない。
- 保存先: `assets/mobies/<id>.webp`。

禁止:
- 実在のブランド名・ロゴ・キャラクター・商品名（服や小物は、特徴だけをオリジナルの形で描く）。
- 武器、暴力、危険な行為の表現。流血や攻撃的なポーズ。
- コードを触る。追加は `assets/mobies/` と `MANIFEST` だけ。

## 平成ギャルモビー `galmobby`

2000年前後の「ギャル」を、もびの世界で、かわいく盛った姿。

- **毛並み・肌（体の毛）:** 明るいキャラメルのブラウン、または日焼け色。既存の濃い色のモビーと並んでも区別できる色。
- **髪（頭の毛）:** **茶髪**の、ふわっと盛った長めのウェーブ。メッシュで明るい色を混ぜてもよい。巻き髪、前髪、大きなシュシュやヘアクリップ。頭の毛の質感は、既存のモビーの毛と同じ手芸っぽい質感。
- **服:** **ヒョウ柄**。短めのトップス（またはジャケット）にヒョウ柄、ミニスカートかショートパンツ。ヒョウ柄は柄をはっきり見せる（ベージュ地に焦げ茶の斑点、金のふち）。ゲームパッドは隠さず、トップスの上に出す。
- **小物（盛る）:** 大きなフープのイヤリング、ラインストーンのチョーカー、ネイルをデコった手（短い手に小さなラインストーン）、デコったストラップをつけた小さなケータイ、厚底のサンダルかブーツ、ゆるめのソックス。
- **顔:** 大きい目に**ばっちりのまつげ**と、ほんのりチーク。レンズの目は変えない（小さなラメやキラキラのまつげを足す程度）。口は小さく笑う。
- **ポーズ:** 片手を腰に当てる、またはピースを出す、明るくノリのいい立ち姿。
- **雰囲気:** 平成の最盛期の、派手で明るくキラキラ。古びた・レトロっぽい表現はしない（`docs/codex-event-assets-taste.md` の「当時の新品」の方針と同じ）。

最初の確認: 1体を作り、既存のモビー（`mobibou.webp`）と並べた確認用画像（`previews/`）、ファイル名、寸法、容量を報告する。
