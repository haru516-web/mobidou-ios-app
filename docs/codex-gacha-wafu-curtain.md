# Codex 向け ガチャの幕を和風に作り直す

ガチャの導入で使っている幕(`assets/gacha/curtain-left.webp` / `curtain-right.webp` / `curtain-valance.webp`)は、いま**西洋の緞帳**(深紅のビロード、金房)です。
縁側・漆・半纏のモビーという世界観に合わせて、**日本の芝居小屋の「引き幕」**に描き直してください。

- **作業ブランチ**: `codex/gacha-wafu-curtain`(用意済み。最新の `claude/ui-navigation-overhaul` から切ってあります)。ワークツリーは Codex が自分で作ってください。
- **コードは触らない。** 3つの素材を**同じファイル名・同じ寸法で差し替える**ので、コード側の変更は要りません。追加してよいのは `assets/gacha/` の画像、`docs/gacha-assets-prompts.md` への追記、`docs/gacha-assets-verification/` の確認記録だけです。
- 画像生成と後処理(透過、寸法の正規化、容量、確認画像、ピクセル検査)は、`docs/gacha-assets-prompts.md` と `docs/gacha-assets-verification/README.md` で前回までにやったのと**同じ手順・同じ基準**で行い、同じ形式で記録する。
- 出力は WebP(品質90前後、アルファ維持)。原本 PNG は残さない。**1枚あたり 900,000 bytes 未満**。
- 画像の中に、文字・数字・ロゴ・透かしを描かない。**家紋も入れない**(下の「やらないこと」を参照)。
- 差し替え前の3枚は git の履歴に残るので、別名保存は不要。**pushはしない。**
- 1コミットにまとめる。

## 何が起きる画面か(絵を描く前に読む)

1. 待っている間、幕は**閉じていて、画面全体を覆う**。中央に紐が垂れる(紐は別素材 `rope.webp`、触らない)。
2. 紐を引くと、幕が**左右の端へ横にすっと引かれて開く**。向こうに縁側(`stage-bg.webp`)が見える。
3. 幕が開いたあとも、**上の飾りだけは残る**。その下の縁側で、モビーが荷車を引いてくる。

実際の見え方(375×812 の端末の場合):

- 左の幕と右の幕は、それぞれ**画面の半分より 30px 広く**表示され、閉じたとき中央で重なる。
- 縦の長さは画面いっぱい(画像の縦横比のまま端末の高さに合わせて引き伸ばされる)。**端末によって縦が多少伸び縮みする**ので、縦方向に繰り返す柄や細かい文様は避ける。
- 上の飾りは画面の幅いっぱいに表示され、高さは約 100px(幅の 27%)。その真下の y=76 前後に、**「ひく」「購入」のタブ**(生成り色の文字)が重なる。飾りの**下 3 分の 1 は、模様を弱めた静かな帯**にして、タブの文字が読めるようにする。

## 世界観と共通スタイル

- 既存の `assets/gacha/stage-bg.webp`、`box-body.webp`、`box-front.webp`、`cart/` のシートを開いて、**光・質感・色味をそろえる**。夜明け前の縁側、飴色〜焦げ茶の漆、金の細工、朱。
- 光源は左上の柔らかい自然光。布の襞は、各襞の左が明るく右が暗い。
- 透過指定のものは完全な透過背景。縁に白フチ・黒フチ、市松模様を焼き込まない。
- 西洋風の要素(房飾り、金のフリンジ、ドレープの花綱、ビロードの艶)は**使わない**。

## 幕のデザイン(2案から選ぶ。理由を記録に書く)

どちらも**縦縞の木綿の引き幕**で、重く垂れる布の質感にする。ビロードの艶は出さず、**木綿の目と、洗い込んだ柔らかさ**を出す。

- **案A: 定式幕(じょうしきまく)** 歌舞伎の本式。**黒・柿色(くすんだ橙)・萌葱(もえぎ、深い緑)**の太い縦縞を、この順に繰り返す。縞の幅はそろえ、画面の幅に対して縞が 9〜12 本入る太さ。色は少し褪せた木綿の色にする。
- **案B: 朱の無地の引き幕** 朱(深い赤、わずかに褪せた)の無地に、**白抜きの細い縦縞**を 2 本だけ入れる。上の縁と裾に、生成りの太い縁取り(乳=ち。幕を通す輪を縫い付ける帯)。

縁側・漆の世界観には案Aのほうが合うと見ていますが、**生成した絵を見て、よい方を選んでください**。

共通の作り込み:

- 上端に、**幕を吊る生成りの帯(乳)と、そこに通した輪**を等間隔で見せる(ただし上の飾りの下に隠れる部分が多いので、強く描かなくてよい)。
- 襞は縦に太く、少なめ。光源に合わせて陰影をつける。
- 下の裾は、**直線に近く、布の重みでわずかに波打つ**程度。房や金の縁取りは付けない。裾に**細い重り(薄い黒の帯)**が入っていてよい。
- 縞の継ぎ目や襞で、色がにじんだり、別の色が混ざったりしない。

## 素材

### W-1 `assets/gacha/curtain-left.webp` と `curtain-right.webp`(各 700×2532、透過)

- 左の幕と右の幕。閉じたとき中央で合わさる。
- **2枚が中央で 60px 重なる**ように作る(左幕の右端 60px と、右幕の左端 60px。いまのコードは、この前提で左右の幕を画面の中央に寄せている)。重ねたときに、**縞が連続して見え、継ぎ目が目立たない**こと。縞の位置は、左幕の右端と右幕の左端でそろえる。
- 引き幕は**中央側の端も、外側の端も、縦の直線**でよい(洋風のような中央のアーチは不要)。外側の端は画面の外へはみ出す前提なので、直線に切ってよい。
- 中央側の端のすぐ内側に、幕の端を手で握って引く**小さな皺のたまり**を作ってもよい(強くしない)。
- 背景は透過。

### W-2 `assets/gacha/curtain-valance.webp`(1170×320、透過)

幕を吊る**上部の飾り**。洋風の垂れ飾りの代わりに、次のどちらかにする(幕に合う方。記録に書く)。

- **案A: 木の鴨居(かもい)と幕串** 飴色〜焦げ茶の漆の太い横木が上端にあり、その下に、**生成りの布の短い垂れ**を下げる。横木の中央に、紐を通す**小さな金の輪**(紐は画像に描かない)。
- **案B: 水引(みずひき)幕** 上に渡す、細い横長の幕。濃い藍か黒の無地に、下辺は**浅い波形**。中央に、紐を通す小さな金の輪。

制約:

- **画像の中央に、直径 50px 前後(画像の幅 1170 に対して)の金の輪**を、上端から 60px ほどの高さに置く。紐はこの輪から下へ垂れて見える。輪は、紐の画像(`rope.webp`)が重なって見えるように、**輪の穴を抜く必要はない**(紐が手前に描かれる)。
- 高さ 320px のうち、**下 100px は静かな帯**(模様なし、色は上の部分の下端から自然に続く暗い色)にして、タブの文字が重なっても読めるようにする。下辺は波形でも直線でもよいが、**透過との境に白フチ・黒フチを出さない**。
- 幅いっぱい(1170)に描く。左右の端で切れていてよい。
- 背景は透過。

## やらないこと

- **家紋・屋号・文字・数字・ロゴ**は描かない(実在の劇場や家の紋に似るのを避けるため。幕は無地と縞だけにする)。
- 画像の縦横比、寸法、ファイル名を変えない。
- 紐(`rope.webp`)、背景、箱、荷車のシートは触らない。
- 実在の劇場の幕の写真や、特定の劇場の意匠の模写をしない。伝統的な色の並びと布の質感だけを参考にする。
