# 御朱印アート

ビルトイン image_gen で生成。ユーザー添付の `mobbyyellow.PNG` を追加分を含む全御朱印のキャラクター造形参照に使用。

片目はレンズ、胸元に十字操作キー、斜めに配置した丸ボタン2つを維持。短い手足・丸みのある四角い体に、注連縄の光輪を加えたモビ神として再構成。

追加36枚を含む42枚は、名称に「もび」を含む本アプリ専用の創作名です。実在施設との関連はありません。公開Web検索で同名施設は確認されませんでしたが、世界中の未公開名称との一致まで保証するものではありません。
