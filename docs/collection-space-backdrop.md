# コレクション3D一覧の背景画像（360°）

## 目的
コレクション画面左上の一覧ボタンから開く3D空間の背景に使う、周囲360°のパノラマ背景を作る。
見る人は空間の中心に立ち、周囲を所持品（御朱印・キーホルダー）が回る。背景はその奥に張られる。
コードは `src/components/CollectionSpace.tsx`（`Backdrop`）が読み込み済み。画像を置いて配列に追加するだけで反映される。

## 作るもの
360°を **4分割**した画像 **4枚**。1枚が水平90°分。

| 項目 | 値 |
| --- | --- |
| 枚数 | 4（`space-bg-1` 〜 `space-bg-4`） |
| 1枚の画角 | 水平90° × 垂直150° |
| 寸法 | 1536 × 2560 px（縦長 3:5） |
| 形式 | WebP（アルファ不要）、1枚あたり目安 700KB 以下 |
| 置き場所 | `assets/collection/space/space-bg-1.webp` 〜 `space-bg-4.webp` |
| 並び | 1→2→3→4 の順に、見ている人の右へ進む。1番が開いた直後の正面 |

### 継ぎ目の条件（最重要）
- 画像 *n* の**右端**と画像 *n+1* の**左端**が、絵として連続すること。
- 画像4の右端は画像1の左端につながる（ぐるっと一周して閉じる）。
- 進め方の推奨: まず 6144 × 2560 の1枚の連続パノラマを作り、1536px幅で4等分に切る。切る前に左右端が一周してつながることを確認する。
- 上端・下端は暗い紺 `#1B1426` に自然に溶けること（3D空間の背景色がこの色のため。垂直150°を超える範囲はこの色が見える）。

### 絵の要件
- 画風は既存のもび道に合わせる（和紙・水彩寄りの、夕暮れから夜の神社の参道のような世界。`assets/` 内の既存背景を参照して色味を揃える）。
- 手前〜遠景の奥行きのある景色。見る人の周囲360°を取り囲む。
- 浮かぶアイテムを引き立てるため、中央の水平帯（垂直中央±35°）は情報量を抑え、コントラストを弱めに、やや暗めにする。
- 人物・モビー・キャラクター・文字・御朱印・ロゴ・UI は描かない。
- 光の粒や灯りは小さく控えめに。アイテムと見分けがつく大きさの物体は置かない。

## 組み込み
1. 画像を `assets/collection/space/` に置く。
2. `src/components/collectionSpaceBackdrop.ts` の配列に、1→4の順で `require` を並べる。

```ts
export const SPACE_BACKDROP_TILES: readonly any[] = [
  require('../../assets/collection/space/space-bg-1.webp'),
  require('../../assets/collection/space/space-bg-2.webp'),
  require('../../assets/collection/space/space-bg-3.webp'),
  require('../../assets/collection/space/space-bg-4.webp'),
];
```

3. 検証: 形式・寸法・容量を一括確認し、4枚を横に並べた連結プレビュー（継ぎ目が分かる）を `docs/` に1枚置く。
   向きが鏡写しになる等のコード側の不具合が疑われる場合は、画像を直さずに報告する。
