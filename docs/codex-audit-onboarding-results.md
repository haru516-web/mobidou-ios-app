対象: `claude/ipad-collection-fix`（`688910f`）。静的監査であり、実機再現や全端末での動作保証は行っていない。

## P1: ストレージ読み込み失敗後におみくじで停止

`src/services/useJourney.ts:227,257`、`App.tsx:569,1300`。`AsyncStorage.getItem` が失敗すると `readOnly` となり、その後の `change` が無視されるが初回導線には入れる。おみくじが抽選済みにならず、閉じる操作も無効。読み込み失敗時の再試行・復旧画面、または一時状態で完了できる経路を設ける。

## P1: ガチャの結果確定前に拡大を戻すと完了ボタンが出ない

`src/components/GachaScreen.tsx:358,473,619,676`。自動拡大が 0.95 に達する前に画面をタップすると拡大が反転し、`panelReady` が立たない。自動拡大は再実行されず、もう一度タップして拡大するまで「おわる」が出ない。ガイド中に閉じる手段もない。完了ボタンを拡大率に依存させない。

## P1: おみくじ演出が中断されると閉じられない

`src/components/OmikujiExperience.tsx:71-78,83-85`、`App.tsx:569,1298-1306`。演出のコールバックが `finished: false` の場合、`omikujiAnimating` が解除されず「ホームへ進む」が出ない。中断・失敗時もフラグを解除して結果表示、再試行またはスキップに進める。実機での中断発生は未確認。

## P1: HealthKit 応答待ち中は「あとで」も無効

`src/components/ConnectStepsPrompt.tsx:14-15`、`src/services/useJourney.ts:294-305`。権限要求や歩数読み取りの Promise が戻らないと `busy` が継続し、両ボタンが無効。待機中も「あとで」を有効にし、遅れて返った結果が後続状態を上書きしないようにする。タイムアウトや再試行も設ける。

## P2: メニュー画面を開いたまま fail-safe が進む

`src/components/FloatingMobby.tsx:314`、`App.tsx:680-700`。`floatingDrag` 中のメニュー項目押下で、メニューを閉じたことにより `homeOmikuji` に遷移し、同時に通知やキャラ変更画面も開く。そのまま 15 秒でおみくじモーダルへ進み、画面が重なる。ガイド中のメニュー項目を無効化するか、別画面表示中はタイマーを停止し、遷移時の画面状態を整理する。

## P2: モビーの案内枠と実位置のずれ

`App.tsx:1281-1283`、`src/components/FloatingMobby.tsx:164-176`。枠は固定の `mobbySpot.offset` に置かれる一方、実体には保存位置・画面サイズ・下部余白による補正がある。端末や復元位置によってずれる可能性があり、枠をタップしても反応しない。実際の対象を測定し、移動やサイズ変更時も追従させる。Dynamic Island を含む端末での実測は未実施。

## P2: オープニング・初期読込の回復手段不足

`src/components/OpeningExperience.tsx:85-105,111-119`、`App.tsx:1131`。幅未測定時は開始操作が効かない。自動演出が `finished: false` で終了すると `autoRunningRef` が戻らない。ストレージやフォント読込の Promise が完了しない場合も読み込み画面に留まる。開始・スキップ、演出中断後の再操作、初期読込の回復手段を設ける。

## P2: Web プレビューは後半を通らない

`App.tsx:916-923`。`?onboarding-preview=1` はプレゼント受取でガイドを終了し、キャラクター紹介・ガチャ・歩数連携を検証できない。ダミーの木札、抽選結果、歩数連携を用い、後半まで通せるプレビューを用意する。

## 補足

- `App.tsx:703-717,955` のルート選択 effect は、通常の初回で `journey.ready`、アカウント画面終了などが揃えば発火する構造。ただしストレージ読込失敗後は `selectRoute` の状態変更が拒否される。
- 無料の初回ガチャとチュートリアル用プレゼントは、コード上は IAP やサーバー請求を待たない。おみくじアトラスの読込完了も進行条件ではない。
- `awardVisible` 等の主要な自動モーダルはチュートリアル中に抑止されるが、ガイド中に開けるメニュー画面との競合は上記の通り。
- 監査時に実機、シミュレーター、Web の通し操作は行っていない。App Store のリジェクト原因は特定できていない。指定 worktree の `git status` は Git の worktree 認識エラーで取得できなかった。
