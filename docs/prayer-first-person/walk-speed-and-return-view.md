# 鳥居の高さ・可変速歩行・帰路の視点（2026-11-01）

- 鳥居は横幅・奥行きを維持し、高さを1.12倍へ変更。
- 移動パッドの上方向入力に6pxの遊びを設け、最大32pxで最大速度。入力強度へ0.75乗の応答を適用。
- 鳥居位置z=3.5を境に、外側の最大歩行速度1.9m/s、内側0.95m/s。帰路も同じ境界で切り替える。
- 位置補間は歩行中に線形とし、移動パッドの強度以外で勝手に加減速しない。
- 視点ボタン短押しは参拝前に社殿方向、参拝後に社殿を背にした帰路方向。
- 拝殿で最後の礼が終わると帰路へ自動で向く。鳥居で最後の礼をするときは社殿へ向き、終えると帰路へ戻る。
- 方向転換は角度の最短距離で補間。動きを減らす設定では補間を省く。

確認: 鳥居外/内・往路/復路での最大速度、半分の入力強度、無入力停止、往復の位置連続性を検査し WALK_STRENGTH_AND_GATE_SPEED_OK。型検査通過。

画面確認: 参拝操作を通過後、自動で帰路を向いた画像と視点ボタン短押し後の画像を撮影して確認。RETURN_VIEW_OK、終了コード0。ブラウザー実行エラーなし。
