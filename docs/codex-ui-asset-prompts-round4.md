# Codex 向け UI アセット 第4弾(修正と不足分)

第3弾の画像をアプリに組み込んで見つかった、**修正が必要なもの**と、**足りないもの**です。
作業の進め方と共通スタイルは、`docs/codex-ui-asset-prompts-round3.md` の「0. 進め方」「1. 共通スタイル指示」と同じです。

- **作業ブランチ**: `codex/ui-assets-round4`(用意済み。最新の `claude/ui-navigation-overhaul` から切ってあります)。
  ワークツリーは Codex が自分で作ってください。
- **コードは触らない。** 追加・置き換えてよいのは `assets/ui-round3/` 配下の画像と、`MANIFEST.md`、`slices.json` だけです。
- 修正するファイルは、**同じファイル名・同じ寸法**で上書きしてください(私が差し替えずに済みます)。
  ただし、新しいファイル(不足分)は新規に追加します。
- 出力は WebP(品質90前後、アルファ維持)。分類ごとに1コミット(R = 修正、M = 不足分)。

## 分類 R: 修正

### R-1 御朱印帳の表紙 12枚(`assets/ui-round3/covers/`)

**問題**: 表紙の周りに、外へにじむ暗い影(ハロ)が焼き込まれていて、アプリで表示すると表紙の後ろに
暗い緑色などの四角い箱が見えます。表紙の外側が、透明ではなく半透明の暗い色になっています。

対象: `circuit` `circuitWater` `compassion` `compassionMoon` `mountain` `mountainRidge` `sanctuary` `sanctuaryDawn` `story` `storyRiver` `vow` `vowSevenLights`(各 1024×1536)

```
表紙の絵、題箋の文字、意匠、寸法、ファイル名は、今のものと完全に同じにする。変えるのは表紙の外側だけ。
- 表紙の外側(本の輪郭の外)は、完全な透明(アルファ 0)にする。影・ハロ・にじみを焼き込まない。
- 表紙の輪郭は、はっきりした縁にする(綴じ糸のある左端も含めて)。角は少しだけ丸みのある実物の本の角。
- 影は、アプリ側で必要なら付けるので、絵には入れない。
- 既存の第3弾の画像を開き、外周の半透明ピクセル(アルファが 0 でも 255 でもない領域)が、
  表紙の縁の 1〜2px のアンチエイリアスだけになっていることを確認する。
```

### R-2 襖の柄(`assets/ui-round3/collection/collection-cabinet-fusuma-full-v1.webp`、1024×1536)

**問題**: 墨の山水と松が濃く、手前に飾る御朱印やキーホルダーが読みにくくなります。

```
同じ意匠(金の砂子地に、山水と松、朱の紅葉)・寸法・ファイル名で、コントラストを大きく下げる。
- 墨の山水と松は、薄墨の淡い滲みにする(濃い黒を使わない)。最も濃い部分でも、明るい茶灰程度。
- 朱の紅葉は、小さく淡くする。
- 全体は、生成りと淡い金の明るい地。手前に置く赤い台や、色のある御朱印が、はっきり浮いて見えること。
- 継ぎ目は、縦の襖の合わせ目(3枚の襖の境)以外に目立つ線を置かない。
```

### R-3 主ボタンの色(`assets/ui-round3/ui/button-primary.webp` と `button-primary-pressed.webp`、各 1400×320)

**問題**: 主ボタンが淡いサーモンピンクに見え、他の朱の要素(朱の落款、選択の印)と色がそろいません。

```
同じ形(手切りの和紙の帯、縁の不規則さ、影)・寸法・ファイル名・スライス幅(左右 150px)を保ち、色だけを変える。
- 紙面は、深い朱(#A54E42 に近い、落ち着いた朱)。和紙の繊維は、少しだけ明るく透ける程度。
- 生成りの文字を載せたときに、はっきり読めること(明るさの差を大きく)。
- pressed は、同じ朱を少し暗く(約 12% 暗く)して、紙が沈んで見えるようにする。
- secondary(生成り)や disabled(灰)は、変えない。
```

### R-4 設定アイコン(`assets/ui-round3/icons/icon-settings.webp`、192×192、透過)

**問題**: 十字に輪の、照準のような絵で、設定だと分かりません。

```
黒一色の墨の筆で描いた、歯車の絵に描き直す。
- 8つの歯を持つ歯車。輪郭は、筆の始まりが濃く終わりが細くかすれる線で、機械的な正円・直線にしない。
- 中央に丸い穴。
- 他のアイコンと同じ筆の太さ・余白 10%・透過背景。黒一色(色はアプリ側で付ける)。
```

## 分類 M: 不足分(新規追加)

いま、アプリのアイコンのうち、筆のアイコンが無いために、記号だけの機械的な絵のままになっているものです。
すべて `assets/ui-round3/icons/` に、既存のアイコンと同じ手ざわり(黒一色の筆、192×192、透過、余白 10%)で作る。

| ファイル | 意味・使う場所 |
|---|---|
| `icon-document.webp` | 今日のおみくじ(通知の「今日のおみくじを引こう」)。巻物のような、一枚の紙と短い筆の文字の線 |
| `icon-navigate.webp` | 次の目的地(通知の「次は〇〇」)。筆で描いた、斜め右上向きの矢じり |
| `icon-grid.webp` | 一覧。田の字(2×2の四角)を、筆で描いたもの |

```
すべて同じ筆の太さ・かすれ・傾きでそろえる。黒一色の墨。始まりが濃く、終わりが細くかすれる。
機械的な直線・正円にしない。192×192、透過、余白10%。
既存の icon-map / icon-list / icon-collection を開いて、線の太さと質感をそろえる。
```
