## 1. ホームの通常表示

通常のホームは、既存のブランドヘッダー（設定を含む）、吹き出し付きの選択中モビー、その直下のホームカード2枚、下部ナビだけで構成する。

ホームカードの左右位置は保存された選択順に従う。カードの下へフッター文、追加カード、歩数ボタン、4項目目のウィジェットを並べない。

```text
ブランド・設定
吹き出し
選択中モビー
┌──────────────┬──────────────┐
│ 左カード     │ 右カード     │
└──────────────┴──────────────┘
下部ナビ
```

2枚は同じ高さの2列カードとし、コンテンツ幅が狭くなっても横2列を維持する。文字は省略・折り返しを使ってカード内に収め、既存の御朱印画像・巡礼画像・実データを再利用する。

## 2. ホームカードの候補

カスタムで選べる候補は次の4つ。通常ホームには、このうち選択された2つだけを表示する。

| ID | 表示 | 内容と導線 |
| --- | --- | --- |
| `goshuin` | 御朱印 | 現在の巡礼で最新または最初の適切な御朱印を表示。タップで既存の御朱印詳細、詳細から御朱印帳へ移動できる |
| `miniature` | 巡礼ミニチュア | 現在選択中の巡礼と既存巡礼画像を表示。タップで既存の巡礼選択を開き、コースを選び直せる |
| `map` | 巡礼マップ | 現在の巡礼を背景にしたマップカード。タップで既存のおでかけ画面の巡礼マップを開く |
| `steps` | 歩数count | 現在の歩数、次の御朱印までの残り歩数、進捗を表示。タップで既存のおでかけ画面の歩数へ移動する |

## 3. カスタム操作

ホームのカードの長押し、または設定の `ホームのカードを編集` から `ホーム画面カスタム` を開く。

- カスタム画面には、左枠・右枠の現在の2選択と、4候補を表示する
- 左枠または右枠を選んでから候補をタップすると、その枠を置き換える
- 既にもう一方の枠に選ばれている候補をタップした場合は左右を入れ替える。重複は作らない
- `左右を入れ替え` でも左右順を交換できる
- `完了` は2枠の選択と順序を保存して閉じる
- ヘッダーの `×` または Android の戻る操作は、編集中の変更を破棄して閉じる
- 背景タップでは閉じない

初期値は `goshuin`（左）+ `miniature`（右）。

## 4. 保存と旧データ移行

保存先は既存の端末ローカルキー `@mobidou/journey/v1`。保存する値は次の2要素タプルである。

```ts
type HomeWidgetId = 'goshuin' | 'miniature' | 'map' | 'steps';
type HomeWidgetOrder = [HomeWidgetId, HomeWidgetId];
```

4候補から必ず異なる2つを保持する。旧バージョンの4要素 `homeWidgetOrder` が残っている場合は、配列を左から読み、妥当な異なるIDの先頭2つへ移行する。2つ集められない不正値は初期値へ戻す。未知の値・重複値でホームに同じカードを2枚表示しない。

編集中の選択は一時状態に留め、`完了` を押したときだけ保存する。

## 5. 下部ナビと画面内の移動

2026-09-29 改訂。

**画面内のタブ（セグメント切り替え）は使わない。** 各タブは1枚の縦スクロール画面にまとめる。画面内の移動は、浮遊するポップボタンで行う。

下部ナビは、既存の和紙フレームのデザイン（アイコンと赤いインジケーター）をそのまま使う。旧メニューボタンがあった場所まで、フレームを横いっぱいに広げている。

| タブ | 画面の構成 | ポップボタン |
| --- | --- | --- |
| 御朱印帳 | 巡礼名、表紙または見開き | `目次`（御朱印の一覧シートを開き、選んだページを開く）、`巡礼`（巡礼を選び直す） |
| おでかけ | 歩数リング、次の目的地、メインボタン（上から相棒モビーが覗く）、巡礼絵図 | `更新`/`連携`、`絵図`（巡礼絵図までスクロール） |
| コレクション | 展示室 → 御朱印 → ミニチュア → 授与品 | `御朱印`、`ミニチュア`、`授与品`（各見出しまでスクロール） |

ポップボタン（`PopButton`）は、ゆっくり上下に浮遊し、押すと縮む。今は仮の丸ボタンを表示している。専用画像は `src/data/popButtonImages.ts` の該当IDに登録すると差し替わる（240×240前後、背景透過の正方形）。

## 6. モビー（浮遊キャラ）

モビーはドラッグで画面内の好きな場所へ動かせる。位置は端末に保存する。ホームを含む全タブに表示する。

タップすると、モビーの周りに4つのポップボタンが飛び出す。ボタンは画面の中央側へ扇状に並ぶ。

- `キャラ変更`
- `通知`（未読数のバッジ）
- `プレゼント`（未受け取り数のバッジ）
- `フレンド`

モビー本体のバッジには、未読の通知と未受け取りのプレゼントの合計を出す。

- **通知**：端末内の記録から作る。サーバーは不要。
  - やること：おみくじ、結願、巡礼選び、歩数連携
  - いまの旅：次の目的地まで何歩か
  - できごと：授かった御朱印
- **プレゼント**・**フレンド**：サーバーが必要なので、画面だけを作ってある。
  - データは `src/services/social.ts` を経由する。本番では空の状態を表示し、体験モードではサンプルを表示する。
  - サーバーにつなぐときは、`SERVER:` と書いた関数を API 呼び出しに置き換える。画面側の変更は不要。
- `モビーを選ぶ` ポップアップは、既存の `PET_CHARACTERS` 17体を表示する。

## 7. アクセシビリティとモーション

- タブ、セグメント、案内の各操作に日本語のアクセシブルラベルと選択状態を付ける
- 文字は最小11pt、本文は13pt以上を目安にする
- 写真の上の文字には半透明の下地を敷く
- タップ領域は44pt以上
- Reduced Motion では移動を短いフェード（160ms）にする

## 9. ホームカード

ホームのカードはショートカットとして動く。拡大ポップアップ（別の縮小版画面）は廃止し、タップしたら本物の画面を直接開く。

- 御朱印 → 御朱印詳細（そこから `御朱印帳でこのページをひらく`）
- おみくじ → おみくじ
- 巡礼マップ → おでかけの巡礼マップ
- 歩数 → おでかけの歩数

補足：保存値の ID `miniature` は、歴史的経緯でおみくじカードを指す。保存データとの互換のため ID は変更していない。
