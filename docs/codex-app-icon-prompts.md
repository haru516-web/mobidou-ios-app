# Codex 向け アプリアイコン案(5パターン)

App Store とホーム画面に出す「もび道」のアイコンを、**5つの違う案**で作ってください。採用する1案を、私が選びます。

- **作業ブランチ**: `codex/app-icon`(最新の `claude/ui-navigation-overhaul` から切る。ワークツリーは Codex が自分で作る)。
- **コードは触らない。** 追加してよいのは `assets/icon-proposals/` の画像、`assets/icon-proposals/MANIFEST.md`、`docs/gacha-assets-prompts.md` と同じ形式の制作記録 `docs/app-icon-notes.md` だけ。
- 1コミットにまとめる。pushはしない。

## 0. 必ず守る仕様(iOSアイコンの決まり)

- 寸法は **1024×1024 px**、形式は **PNG**、色空間は sRGB。
- **透過なし**(アルファチャンネルを持たせない)。背景まで塗りきった、**四角い全面の絵**にする。角丸にしない(角丸はiOSが自動でかける)。
- 絵の中に、**文字・数字・透かしを描かない**。アプリロゴの図柄そのもの(鳥居、モビー、波)は文字ではないので、使ってよい。
- 大事な要素は、画像の中央 **約 80%(縦横とも 100〜924 px の内側)**に収める。四隅は iOS が丸く切る。
- **小さくても読める**こと。60×60 px(ホーム画面の大きさ)に縮めても、「円のロゴ」と「キャラ3体がいる」ことが分かる。細かい文様や、小さな文字のようなものは避ける。
- 5案は、**構図・色・背景を、はっきり変える**。同じ構図の色違いにしない。

## 2. 世界観と共通スタイル(各プロンプトの冒頭に付ける)

```
スマートフォンのアプリアイコン(正方形、全面塗りつぶし、1024×1024)。アプリ「もび道」(歩いて架空の御朱印を集める巡礼アプリ)。
和風。実物の和紙、墨、朱、金、麻、藍染の手ざわりのある、手作りの工芸品のような絵。光沢のある 3D レンダリング風
(つるつる、ガラスの反射、CG 的なグラデーション)は禁止。縁は筆で引いたかすれ。光源は左上の柔らかい自然光。
参照画像のアプリロゴ(円の中の鳥居とモビー)を、形と配色を変えずに、絵の中心の主役にする。
参照画像の3体のキャラクター(もびりん、モビ坊、ばぶモビー)を、造形をそのままに、すべて入れる。
文字・数字・透かしを描かない。透過はなし、角丸にしない。
```

## 3. 5つの案

### 案1 朱の和紙と三体の見守り(いちばん素直な構図)

- 背景は、深い朱(わずかに褪せた)の和紙。ところどころ、金の細い雲(霞)。
- 中央に、アプリロゴの円を **大きく**(画像の幅の約 60%)置く。
- 円の左下から、もびりん。右下から、モビ坊。中央の下に、ばぶモビーが座る。3体は、円の前に少し重なってよい。
- 全体は左右対称に近く、安定した構図。小さくしても、円と3つの丸い影が見える。

### 案2 夜明けの参道

- 背景は、夜明けの空(藍から朱、淡い金へのやわらかいぼかし)と、遠い山の影。
- 画面の下半分に、石段の参道が奥へ伸びる。その上の中央に、アプリロゴの円を**朝日のように**大きく昇らせる(円の下半分が山に隠れてもよい。ロゴの図柄は全部見えること)。
- 参道の手前に、3体が並んで、円を見上げている後ろ姿か、横向き(ばぶモビーは中央で座る)。
- 全体は縦に奥行きがあり、「これから歩く」気持ちを出す。

### 案3 御朱印のような白地と朱の印

- 背景は、生成りの和紙(わずかな繊維の模様)。四辺に、墨のかすれた細い枠。
- 中央に、アプリロゴの円を、**朱の印影のように押した**形で置く(ロゴの図柄はそのまま、周りに朱のにじみ)。
- 円の周りに、3体が小さめに(円の幅の約 40%)寄り添って並ぶ。毛や布の質感は参照画像のまま。
- 全体は余白が多く、静かで品のある印象。小さくしても、白地に朱の円がはっきり見える。

### 案4 藍染と青海波

- 背景は、藍染の木綿(濃い藍、白い糸の目)と、淡い藍で描いた青海波の文様。文様は大きく、少なめに。
- 中央に、アプリロゴの円を置き、円のふちに**金の細い縁取り**を加える。
- 円の左右に、もびりんとモビ坊が、円を支えるように並ぶ。ばぶモビーは円の下で座る。
- 色数を絞って、黒・朱・藍・金・生成りの印象にする。

### 案5 桜の山道(明るい春)

- 背景は、淡い桜色と若草色のやわらかい霞。散る桜の花びらを、まばらに(大きめの花びらを 5〜8 枚)。
- 中央に、アプリロゴの円。円の背後に、山道が曲がって上る。
- 3体が、円のまわりで、それぞれ違う動きをする(もびりんは帽子を持ち上げる、モビ坊は手を挙げる、ばぶモビーは座って見上げる)。参照画像の造形は変えない。
- 全体は明るく、親しみやすい。ほかの4案より、色が淡いこと。

## 4. 完了時の報告

- 5案の画像 `assets/icon-proposals/icon-1.png` 〜 `icon-5.png`(各 1024×1024、アルファなし)の寸法・容量・色空間を表で。
- **アルファが無いこと**を、ピクセル検査で確認した記録。
- 各案を **120 px と 60 px に縮めた並べ画像**(`assets/icon-proposals/small-preview.png`)。明るい背景と暗い背景の両方。
- 各案を、**iOS の角丸の形(角丸 22.37%)で切り抜いて、ホーム画面のように並べた**確認画像。
- 3体のキャラクターが、参照画像と造形が合っているかの確認(ずれた点があれば、正直に書く)。
- 各案の狙いを、1〜2行で。
