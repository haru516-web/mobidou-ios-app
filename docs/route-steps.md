# 巡礼ルート別 必要歩数（2026-10-16 時点）

`src/data/pilgrimages.ts` の実データから自動集計（`scripts/route-steps-report.ts`）。非チュートリアルの各ルートは、すべての区間（出発→最初の地点、地点→次の地点）が最低 8,000 歩に引き上げ済みの値です。

- 「前の地点から」= 前の地点を参拝してから次の地点に着くまでに必要な歩数

- 歩数はルート出発後に加算された分だけが対象（出発前の歩数は含まない）
