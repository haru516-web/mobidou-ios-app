# Codex 向け イベント巡礼アセット（第一回「時をめぐる道」）

イベントモードの画面方針は `docs/event-plan.md` §5、テーマとスポットは同 §2。ここでは画像だけを依頼する。

## 運用

- ブランチ: `codex/event-assets`（基点 `claude/events`）。ワークツリーは `D:/mobby/mobidou-event-assets` を自分で作成する。`node_modules` は `D:/mobby/mobidou-claude/node_modules` へのジャンクションで共有する。
- **コードは触らない。** 追加するのは `assets/event-toki/` と、その中の `MANIFEST.md` だけ。
- WebP 品質90、アルファ維持（透過が要るもの）。**画像内に文字を描かない**（ボタンの文字はコードが描く）。ただし御朱印（G）は既存の御朱印と同じく、朱印と墨書きを絵として含めてよい。
- 画像ごとに1コミット。`MANIFEST.md` に、ファイル名・寸法・容量・（九分割やクロップがあれば）その指定を書く。
- 既存の画像の質感・線の太さ・和紙の色に合わせる。比較用の参照は各項目に書く。

## デザインの共通方針

- **イベントの色:** 通常の画面は朱（#B5432F）の縁が基調。イベントは**藍（#2F4A6B）の縁に、金（#C9A24B）の細い差し色**で、「特別な催し」と一目で分かるようにする。和紙の地は通常と同じ。
- **題材:** 昭和から平成へ時代をたどる架空の旅。昭和レトロ（ブリキ、ラジカセ、黒電話）と平成レトロ（ガラケー、ポケベル、デジカメ）。実在の車種・メーカー・ロゴ・通信会社・商品名・キャラクターは**描かない**。すべてオリジナルの形にする。
- **ヤンキー・暴走族の描写は避ける**（迷惑運転を連想させない）。
- 社は**すべて架空**。実在の神社仏閣や、既存の巡礼の社と似せない。

## A. イベントのポップボタン 6点（512×512、透過）

既存の `assets/pop-buttons/walk-map.webp`（512×512 透過）と**同じ形・大きさ・影・余白**で、縁を藍にして描く。ボタンの文字（ラベル）はコードが描くので、中央に絵だけを入れる。参照: `assets/pop-buttons/book-index.webp`, `walk-map.webp`, `collection-room.webp`。

| ファイル | 絵柄 | 使う場所 |
|---|---|---|
| `assets/event-toki/pop-buttons/event-home.webp` | ブリキの丸目セダンの小さなシルエット（イベント全体の顔） | ホーム（キャラクターの左で浮遊） |
| `.../event-book.webp` | 藍の表紙の御朱印帳 | 御朱印帳（左上） |
| `.../event-gacha.webp` | 藍と金の木札 | ガチャ画面 |
| `.../event-walk.webp` | 道の先に小さな社 | おでかけ（歩数カードの左） |
| `.../event-normal.webp` | 通常の巡礼を表す、朱の鳥居 | イベントモード中に通常へ戻す（おでかけ・コレクション共通） |
| `.../event-collection.webp` | 小さな棚に並んだミニチュア | コレクション（上部の文字の代わり） |

6点は同じ家族に見えること（縁、影、和紙の質感、絵の大きさ）。ふわふわ浮く表現はコード側なので、絵に浮遊の影は足さない。

## B. イベント専用マップ（1024×1536）

`assets/event-toki/map.webp`。参照: `assets/ui-round3/backgrounds/map-washi.webp`（1024×1536、現在の巡礼絵図）。

- 和紙の絵図。道は**下から上へ昭和→平成**と時代が移るように、下半分は昭和（商店街・峠・ドライブイン・銭湯の煙突・レコード坂）、上半分は平成（公園・橋・見晴らし）の景色を、淡く低コントラストで描く。
- 道の上に**8か所の目印**が乗る（コードが丸い目印を重ねるので、絵には社の建物を大きく描かない。小さな屋根の影程度に）。目印は次のおおよその位置（幅・高さに対する割合）に通る道にする:
  1 (.10,.84) / 2 (.34,.72) / 3 (.16,.56) / 4 (.42,.46) / 5 (.72,.54) / 6 (.84,.36) / 7 (.60,.22) / 8 (.86,.10)。道はこれらを順に通る一本の蛇行。
- 文字を描かない。既存マップと同様に、地図の上にカードとモビーが重なっても読めるコントラストにする。

## C. イベントの表紙 1点（1024×1536）

`assets/event-toki/book-cover.webp`。参照: `assets/goshuin-book-covers/circuit.webp`。藍の布張りの御朱印帳。表紙の中央に、昭和と平成を象徴する小さな図案（ブリキの車と折りたたみ携帯のシルエット）を金の線で。文字なし。

## D. イベント限定の木札 1点（256×384、透過）

`assets/event-toki/ticket-event-tag.webp`。参照: `assets/ui-round6/tickets/ticket-gacha-tag-v1.webp`。通常のガチャ木札と同じ形で、**藍の紐と金の縁**にしたもの。クリア報酬で、イベント限定ガチャに使う。

実在の車種・メーカー・携帯会社のロゴや意匠に寄せない。ミニチュアとして可愛く、少し古びた質感（塗装のかすれ、小さな傷）。

## F. 御朱印 8点（1024×1536）

`assets/event-toki/goshuin/<id>.webp`（id は E と同じ）。参照: `assets/goshuin/akane.webp`（朱印・墨書き・紙の質感・構図を既存に合わせる）。各社の名前を墨書きにする。

| id | 社の名前 |
|---|---|
| showa-shoutengai | ひだまり商店街の小社 |
| showa-toge | 峠の見晴らし祠 |
| showa-drivein | 夜明けドライブインの社 |
| showa-sento | 銭湯煙突山の祠 |
| showa-record | レコード坂の御堂 |
| heisei-park | 放課後の公園ほこら |
| heisei-pager | ポケベル橋のたもと社 |
| heisei-century | 世紀末の見晴らし社 |

朱印の印影には、その社のミニチュアを連想させる小さな意匠（E の題材を簡略化）を入れる。昭和の4〜5枚は黄みの強い和紙、平成の3枚はやや白く明るい和紙にして、時代の移り変わりを紙の色でも表す。
