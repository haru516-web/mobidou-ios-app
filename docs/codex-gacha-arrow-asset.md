# ガチャの操作ガイド矢印（Codex依頼）

## 使い方（アプリ側が動かす）

ガチャ画面で「ひもを下へ引く」「箱の前の板を上へ引き上げる」を示す、動く矢印に使う。
アプリは同じ画像を3枚重ね、ずらしながら流して薄く消す。上向きは同じ画像を180度回して使う。
そのため、**下向きの矢印1枚**だけを作る。

## 素材

| ファイル | サイズ | 内容 |
|---|---|---|
| `assets/gacha/guide-arrow-down.webp` | 256×256 | 下向きの矢印（山形・シェブロン）1つ。左右対称。透明背景 |

## 見た目

- 和風の筆で描いた、太めの山形（V字）の矢印。墨の掠れと、和紙のにじみを少し入れる。
- 色は生成り〜白に近い、あたたかい白（`#FFF8E9` 付近）。縁にごく薄い焦げ茶の輪郭（暗いカーテンと明るい床の両方で読めるように）。
- 矢印の軸は付けない。山形だけ。先端はやや丸い。
- 画像の中央に収め、四辺に20px以上の余白を残す。
- 文字や記号は入れない。影は描き込まない（アプリ側で付ける）。

## 共通ルール

- 背景は完全な透明（アルファ）。市松模様や透けた背景の焼き込みは禁止。
- ファイル形式は WebP。50KB以下を目安にする。
- 作風は `assets/gacha/` の既存素材、`docs/codex-gacha-assets.md` の共通ルールに合わせる。
- 生成に使ったプロンプトは `docs/gacha-assets-prompts.md` に追記する。
- コード（`src/`、`App.tsx`）は変更しない。素材と記録だけ。

## 確認

- アルファ付きで、四隅のピクセルが完全に透明であること（`scripts/audit-image-assets.cjs` の手順を使う）。
- 暗い色（`#302D25`）と明るい色（`#C79A62`）の両方の上に重ねて目視し、読めること。
- 完了したらファイルのサイズをコミットメッセージに書く。
