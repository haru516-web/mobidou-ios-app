# ガチャ演出の素材（Codex依頼）

## 演出の仕様（アプリ側が動かす）

真上から見た木箱を、部品を重ねて動かして演出する。1体ごとに、次を繰り返す（5連は5回繰り返す）。

| 順 | 場面 | 動き | 使う部品 |
|---|---|---|---|
| 1 | 紐を引く | 画面上部の紐を下へ引く（ドラッグ）。離すと箱が来る | rope |
| 2 | 転がってくる | 木箱が画面の外から、ごろごろ転がって中央で止まる（回転しながら横へ移動、数回はずむ） | box-lid、box-shadow |
| 3 | 上面が開く | 蓋が先に開き、隙間から光が漏れる | box-lid、box-base、glow-core |
| 4 | 四方が倒れる | 前後左右の側板が、それぞれの方向へ倒れていく。倒れても中身は見えず、強い光で満たされている | box-flap（4枚）、glow-core、glow-rays |
| 5 | 光が弱まる | 光が少しずつ弱まり、やっと中のモビーが見える | glow-core、glow-rays |

真上から見た絵なので、立っている側板は箱の縁の細い帯として見え、倒れると外側へ広がる板として見える。アプリが1枚の板を4方向に回転・拡大して使う。

## 共通ルール

- 場所: `assets/gacha/`（新規フォルダ）。ファイル形式は透明な WebP。
- 背景は完全な透明（アルファ）。市松模様や、透けた背景の焼き込みは禁止。
- 文字や記号は絵に入れない。
- 既存の和紙・水彩・墨の作風に合わせる（`assets/ui-round3/`、`docs/codex-ui-asset-prompts-round4.md` の書式と手順に従う）。
- 影は `box-shadow` 以外には描き込まない（アプリ側で位置を動かすため）。
- 各ファイルは 400KB 以下を目安に最適化する。
- 生成に使ったプロンプトは `docs/gacha-assets-prompts.md` に記録する。
- コード（`src/`、`App.tsx`）は変更しない。素材と記録だけ。

## 素材一覧

| ファイル | サイズ | 内容 |
|---|---|---|
| `box-lid.webp` | 1024×1024 | 桐の木箱の蓋。**真上から**見た正方形。素朴な木目。中央に朱色の紐が十字にかけられ、小さな結び目がある。ごく小さな角丸 |
| `box-base.webp` | 1024×1024 | 同じ箱の**内側を真上から**見たもの。四辺の内壁の細い縁が見え、中央は空の暗い内底。光は描かない（光は別の部品） |
| `box-flap.webp` | 1024×512 | 側板1枚の**外面**。横長の板。木目、上下の細い朱の縁、中央に小さな朱の焼印（家紋のような丸い意匠。文字は入れない）。左右対称で、向きの手がかりがない意匠にする（4方向に回転して使うため） |
| `box-shadow.webp` | 1024×1024 | 箱の下に敷く、やわらかい丸みのある影。中心が濃く、縁は完全に透明へ溶ける |
| `glow-core.webp` | 1024×1024 | 中心が白〜淡い金色の、やわらかい放射状の光。縁は完全に透明 |
| `glow-rays.webp` | 1024×1024 | 中心から放射状に伸びる、金色の光の筋。ゆっくり回転させて使う。縁は透明 |
| `rope.webp` | 256×1024 | 上端が画面外へ続く、朱色の引き紐。下端に房（結び玉と房）。縦長 |
| `stage-bg.webp` | 1170×2532 | ガチャの背景。夜明け前の縁側。板張りの床、障子、遠くの灯り。**中央からやや下に、箱が置ける何もない広い床**を残す。上部は紐が垂れる余白 |

### 各ファイルの見た目の指定

- 木箱の色は、あたたかい明るい桐の色。使い込まれた手触りで、汚れすぎない。
- 朱色は既存の御朱印の朱に合わせる（`docs/ARTWORK.md` を参照）。
- `box-lid` と `box-base` は同じ大きさ・同じ位置の正方形で、重ねるとぴったり合うこと。
- `box-flap` の長辺は、箱の1辺（1024）と同じ長さ。

## 確認

- 8ファイルすべてがアルファ付きで、四隅のピクセルが完全に透明であること（`stage-bg` を除く）。
- 市松模様が焼き込まれていないこと（`scripts/audit-image-assets.cjs` の確認手順を使う）。
- 完了したら、ファイル一覧と各ファイルのサイズをコミットメッセージに書く。
