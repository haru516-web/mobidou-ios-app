# Codex 向け イベント御朱印帳そのもののデザイン（盛り盛り版）

いまのイベントの御朱印帳（`assets/event-toki/book-cover.webp`）は、藍の布に金の細線だけの控えめな表紙で、背景が不透過（通常の表紙は周りが透過）。これを、**表紙・開いたページ・縁の布地**まで、イベント専用の「盛り盛り」デザインにする。

方向は `docs/codex-event-assets-taste.md` と同じ: 藍（#2F4A6B）と金（#C9A24B）の基調に、**昭和のネオン・クロームのギラつき**と**平成のラメ・ホログラム・ラインストーン・パステルのキラキラ**を、ためらわず盛る。「レトロ」にしない（古びた・かすれは描かない。当時の新品として派手で明るく）。実在のブランド名・ロゴ・商品名・キャラクターは描かない。

## 表紙の内容（盛り盛り）
- **全体:** 濃い藍のなめらかな布を土台に、金の雲（霞）と金の細密な縁取り。四隅は金の留め具の装飾。縁に沿って、ネオン管の細い光と、ホログラムの虹色の線をめぐらせる。
- **タイトルの札（中央、縦長）:** 白金の和紙の札に、墨書きの筆文字で **「御朱印帳」** と **「時をめぐる道」**（この2つの文字だけ。ほかに文字は描かない）。札の縁は金、角にラインストーン。
- **15個の宝物のメダリオン（札のまわりに輪になって並ぶ）:** 丸い金縁のメダリオンに、1つずつアイテムを入れる。上から時計回りに、昭和の旧車、バイク、ブラウン管テレビ、ミラーボール、レコード、平成のMDプレーヤー、ポケベル、ポータブルCD、シール帳、PHS、ルーズソックス、ガラケー、厚底ブーツ、コンデジ、デコストラップ。アイテムは、キーホルダー（`assets/event-toki/keychains/`）の形と色にそろえる。昭和のメダリオンは金縁にネオンの光、平成のメダリオンはホログラムとラインストーンの縁。
- **左下（昭和）:** ネオンの看板、クロームのバンパーの一部、夜の街の灯り。**右上（平成）:** 桜の花びら、ホログラムのハートと星、リボン、ビーズのチャーム。左下から右上へ、色が昭和の夜から平成の昼へ移る。
- **背（左端）:** 通常の表紙と同じ綴じ糸（縦の穴と糸）。糸は金。
- 札とメダリオンの輪は、本の中央に収める（四隅の飾りと重ならない）。

## 開いたページの紙（左右）
- 地は、明るいクリーム色の和紙のまま（御朱印と文字が乗る。中央は無地寄りで読みやすく）。
- 縁に、藍と金の二重の罫線。四隅に、昭和のネオン管の角飾りと平成のホログラムの星の小さな意匠（薄く、紙の範囲の内側に収める）。
- 背（綴じ目）の影の位置と濃さは、既存と同じ。

## 守ること
- **形・位置は既存と同じ。** 表紙の本体の輪郭、ページの紙の範囲、背の位置は、コードがその前提で組まれている。変えるのは表面の絵柄・色・質感。
- 表紙以外に文字は描かない。
- 条件を満たしていればそこで止める。磨き込みや全点の再生成はしない。コミットは1回、MANIFEST にはファイル名・寸法・容量だけ。確認用は「既存（左）／イベント版（右）」を並べた1枚（previews/）。
- 実在のブランド名・ロゴ・商品名・キャラクターは描かない。暴走族・不良の描写はしない。コードは触らない（追加は `assets/event-toki/` と MANIFEST のみ）。
