# Codex 向け ガチャ演出アセット(幕・荷車・荷下ろし)

ガチャの導入演出を、次のように作り替えます。そのための画像を作ってください。

1. 紐を引くと、劇場の緞帳のような**幕が左右に開く**(開く前は、幕が画面全体を覆っていて、中央の継ぎ目に紐が垂れている)。
2. 幕の向こうの縁側(`assets/gacha/stage-bg.webp`)へ、**モビーが荷車を引いて入ってくる**。荷車には木箱が載っている。
3. 荷車が止まり、**荷を下ろす**。木箱が床に降りる。モビーと荷車は退場する。
4. そこから、今の「前の板を引き上げて箱を開ける」場面につながる。

- **作業ブランチ**: `codex/gacha-cart-assets`(用意済み。最新の `claude/ui-navigation-overhaul` から切ってあります)。
  ワークツリーは Codex が自分で作ってください。
- **コードは触らない。** 追加してよいのは `assets/gacha/` 配下の画像と JSON、`docs/gacha-assets-prompts.md` への追記、`docs/gacha-assets-verification/` の確認記録だけです。
- 画像生成と後処理(透過、寸法の正規化、容量、確認画像、ピクセル検査)は、`docs/gacha-assets-prompts.md` と `docs/gacha-assets-verification/README.md` で前回やったのと**同じ手順・同じ基準**で行い、同じ形式で記録する。
- 出力は WebP(品質90前後、アルファ維持)。原本 PNG は残さない。**1枚あたり 900,000 bytes 未満**にする(幕と荷車シートは大きいので、必要なら品質を下げる)。
- 画像の中に、文字・数字・ロゴ・透かしを描かない。
- 分類ごと(C・W・U)に1コミット。**pushはしない。**

## 世界観と共通スタイル

- 既存の `assets/gacha/`(特に `stage-bg.webp`、`box-body.webp`、`box-front.webp`)を開いて、**光・色味・質感をそろえる**。夜明け前の縁側、飴色〜焦げ茶の漆、金の細工、朱。
- 光源は左上の柔らかい自然光。影は物の輪郭に沿った薄い接地影だけ(箱型・均一ぼかしのドロップシャドウは禁止)。
- 透過指定のものは完全な透過背景で、縁に白フチ・黒フチ、市松模様を焼き込まない。
- キャラクターは `assets/mobies/mobibou.webp`(黒いふわふわの体、片目、十字のゲームボタン)を**そのまま基準**にして、同じ造形・同じ質感(毛の質感、目、十字の位置)で描く。別のキャラクターにしない。

## 分類 C: 運び屋モビーと荷車(2枚のシート + アンカー JSON)

**運び屋**: `mobibou` が、藍染の半纏(背に小さな朱の紋)と、白い手拭いの鉢巻きを身に着けている。荷車は、古い木製の二輪の平荷車(木の台、太い車輪、前に引き棒)。**荷車の台の上は空**にする(箱は描かない。コード側で本物の箱の画像を載せる)。台の上面は、箱を置ける平らな面にする。

**向き**: 右向き(画面の左から右へ進む)。横から見た構図。台の後ろ(左)に、荷を滑り下ろす小さな斜めの渡し板を付けてよい(上げ下げする)。

**シートの共通仕様**:

- 1つのシートは、**4列×2行の8コマ**を、行優先(左上→右、次の行)で並べる。
- 1コマは **768×512**。コマとコマの間に、**1px の完全な透明の隙間**を入れる(シート全体は 3075×1025)。
- 全コマで、モビーと荷車の**大きさ・接地線(車輪が床に着く位置)・画面上の基準位置**をそろえる(コマごとにずれない)。接地線は、コマの下端から 48px 上。
- 背景は完全な透過。床も影も描かない(接地影は `box-shadow.webp` 相当の薄いものを、コード側で足す)。

### C-1 `assets/gacha/cart/carrier-walk.webp`: 荷車を引いて歩く(ループ)

8コマで、ちょうど1歩行周期(最初と最後がつながって、滑らかにループする)。

- モビーは、体を少し前に傾けて、両手で引き棒を引く。足が交互に出る。毛と半纏の裾が、歩みに合わせて揺れる。
- 荷車は、歩みに合わせて小さく上下に弾む(台の高さが±6px 程度揺れる)。車輪は回る(スポークの位置がコマごとに進む)。
- 表情は、楽しそうで、少し頑張っている。

### C-2 `assets/gacha/cart/carrier-unload.webp`: 荷下ろし(1回再生)

8コマで、次の流れ。ループしない。

1. コマ1〜2: 止まる。モビーが引き棒を下ろし、荷車がすっと止まる(最初のコマは、`carrier-walk` の1コマ目と同じ姿勢から始める)。
2. コマ3〜5: モビーが荷車の後ろへ回り、台を後ろへ傾ける。台の後ろ側が下がり、渡し板が床に届く(荷を滑り下ろせる傾斜になる)。
3. コマ6: 台が最大に傾く(この瞬間に、コード側で箱を滑らせる)。モビーが後ろで支える。
4. コマ7〜8: 台が水平に戻る。モビーが額の汗をぬぐって、一息つく。最後のコマは、引き棒の前に戻って、また出発できる姿勢。

### C-3 `assets/gacha/cart/anchors.json`: 箱の位置

コード側が、荷車の台の上に本物の箱の画像を載せ、台の傾きに合わせて滑らせます。そのために、**コマごとの位置**を書いた JSON を、次の形で作ってください(座標はそのコマの左上を原点とするピクセル、小数可)。

```json
{
  "cell": { "width": 768, "height": 512 },
  "groundLine": 464,
  "walk": [ { "bedX": 0, "bedY": 0, "bedAngle": 0 } ],
  "unload": [ { "bedX": 0, "bedY": 0, "bedAngle": 0 } ],
  "box": { "width": 0, "height": 0 },
  "slideEnd": { "x": 0, "y": 0 }
}
```

- `walk` と `unload` は、それぞれ**8要素**。`bedX, bedY` は、箱を置く台の上面の**中央の位置**(箱の底辺の中央がここに来る)。`bedAngle` は、台の傾き(度、右が上がる向きを正)。
- `box.width/height` は、荷車の上に載せる箱の**表示サイズ**(ピクセル)。荷車の台の幅に対して、箱が自然に見える大きさ(箱は縦長で、`box-body.webp` は 880×1280 の比率)にする。
- `slideEnd` は、箱が滑り落ちて床に着く位置(箱の底辺の中央)。`unload` のコマ6〜7の、渡し板の先の床。
- 数値は、実際の画像から測って書く。推測で書かない。

## 分類 W: 幕(3枚)

劇場の緞帳を、日本の芝居小屋の定式幕のように、**深い朱と濃い藍と生成りの縦の太い縞**、または深い朱の無地に金の縁取りで作る(**どちらか、縁側の世界観に合う方を選び、記録に理由を書く**)。布の重み、縦の太い襞(ひだ)、房飾り。

共通: 画面は 1170×2532 を基準にする。

### W-1 `assets/gacha/curtain-left.webp` と `curtain-right.webp`(各 700×2532、透過)

- 左の幕と右の幕。閉じたとき、中央で合わさる。**幕の中央側の端は、わずかに内側へ弧を描いて垂れ下がる**(上が広く、下で少し開く)。外側の端は、画面の外へはみ出る形で、直線に切ってよい。
- 閉じたとき、2枚が**中央で 60px 重なる**ように作る(左幕の右端 60px と、右幕の左端 60px)。継ぎ目が見えない。
- 下の裾は、金の細い縁取りと、小さな房を等間隔に並べる。裾の線は、直線ではなく、布の重みでわずかに波打つ。
- 襞は縦に太く、光源(左上)に合わせて、各襞の左が明るく、右が暗い。
- 背景は透過。

### W-2 `assets/gacha/curtain-valance.webp`(1170×320、透過)

- 幕の上に渡す、横長の飾り(**幕の上端の吊り元を隠す垂れ飾り**)。金の縁取り、等間隔の小さな房、中央に、紐を通す小さな金の輪(紐は画像に描かない)。
- 下辺は、浅い弧を繰り返す縁(波形)。
- 背景は透過。

## 分類 U: 補助(任意だが、あると良い)

### U-1 `assets/gacha/cart/dust.webp`(4列×2行の8コマ、1コマ 256×256、透過)

箱が床に着いたときの、ほこりの煙。薄い生成りの灰色。1コマ目で小さく、5コマ目で最大、8コマ目で消える。

## 完了時の報告

- 追加したファイルの一覧(寸法・容量・コマ数)。
- `anchors.json` の測り方と、各コマの値の確認方法。
- `carrier-walk` のループがつながっていること、`carrier-unload` の1コマ目が `carrier-walk` の1コマ目と姿勢がそろっていることの確認(重ねて比べた画像を、`docs/gacha-assets-verification/` に保存)。
- 明るい背景(`stage-bg.webp` の板張り)と暗い背景の両方に重ねて、縁に白フチ・黒フチが出ていないことの確認。
- 幕を閉じた状態(左右を重ねて、`stage-bg.webp` の上に置いたもの)の確認画像。
