# 音源と権利

全音源は `scripts/create-audio.cjs` による本プロジェクト用のオリジナル作曲・手続き合成。外部録音、既存楽曲、サンプル音源、声は使用していません。音源の利用に外部素材のライセンス条件はありません。

箏の減衰する倍音、尺八・篠笛の息、笙の管音、神楽鈴の非整数倍音、柝・木鉦の短い共鳴、紙・衣擦れを数式とシード固定の雑音で表現。伝統旋法の五音を中心に作曲。実演録音の再現品質を保証するものではありません。

制作ツール: Node.js（MIT）、FFmpeg 8.0.1 full_build-www.gyan.dev（`ffmpeg -L` でGPL version 3 or laterを確認。音源にFFmpeg本体を同梱しない）、内蔵AAC encoder。再生: expo-audio（MIT）。これらのソフトウェアのライセンスは生成音声を制限しません。

短いSFXのLUFSは400msまでゼロ補完して計測した値。固定ゲインで書き出し、ピーク余裕を優先。AACエンコード後の音量・継ぎ目と実機試聴は別途検証が必要です。
