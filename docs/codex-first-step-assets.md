# Codex 向け作業指示: 「はじめの一歩」ルートの画像（2026-10-05）

## 何を作るか（背景）
新しく遊び始めた人が「歩く → 御朱印がもらえる → 寺社のミニチュア（キーホルダー）がもらえる」を最初の一日で体験できるように、
**1,000歩で達成できる入門ルート「はじめの一歩」**を追加する。社は1か所だけ。1,000歩で御朱印と、確定でミニチュアが手に入る。

コード・文章・設定は Claude が担当する。**あなた（Codex）の担当は画像4点だけ。コードには触らない。**

## 世界観メモ
- 舞台は「もびの世界」。社の名前は「○○もび△△社」の形で、小さな毛玉の生き物「モビー」と歩く和風の巡礼。
- 新しい社は **一歩もび標社（いっぽもびしるべしゃ）**。場所は「もびの入口・一里塚の小径」。
  - 一言: 「ここから、あなたの道が始まる。」
  - ご利益: 「最初の一歩・道しるべ」
  - 色: 土と草の落ち着いた色（`#A8946A` を基調に、若草色を少し）
  - モチーフ: **道標の石、一里塚、わらじ、足あと**。やさしく、旅の始まりを祝う雰囲気。
  - **避けるモチーフ（既存の社と重なる）**: 石灯籠・灯り・篝火（灯社・灯宮の各社）、朝焼け・朝の光（暁もび灯宮・朝もび露宮・朝霧もび社）、星（一番星もび宮ほか）、鳥居を主役にすること（多くの社の背景に出る）。
- 既存の絵の画風（和紙・水彩寄りのやわらかい質感、輪郭は強すぎない）に揃える。文字は入れない（御朱印の社名の筆文字は除く）。

## 作る画像（4点）

### 1. 御朱印 `assets/goshuin/ippo.webp`
- 1024×1536 の縦長、WebP。
- 参考にする既存画像: `assets/goshuin/rain.webp`、`assets/goshuin/morikage.webp`（背景の扱い・朱印の構成・余白を揃える）。
- 内容: 「一歩もび標社」の御朱印。朱の社印、筆の墨書（社名「一歩もび標社」と日付欄の空き）、小さな道標か足あとの意匠。
- 背景は既存の御朱印に合わせる（透過か和紙地かは参考画像と同じにする）。

### 2. ミニチュア（キーホルダー）`assets/collection/keychains/keychain-ippo-v1-transparent.webp`
- 1024×1536、**背景透過**の WebP。
- 参考: `assets/collection/keychains/keychain-rain-v1-transparent.webp` と同じ構図・影・紐の付き方。
- 内容: 小さな道標の石と足あとをかたどった、手のひらサイズのキーホルダー。金具と紐は既存と同じ作り。
- 切り抜きの縁に白い縁取りやチェッカー模様が残らないこと。

### 3. 御朱印帳の表紙 `assets/ui-round3/covers/firstStep.webp`
- 1024×1536、WebP。
- 参考: `assets/ui-round3/covers/sanctuary.webp`（ほかの表紙と並んだときの格を揃える）。
- 内容: 「はじめの一歩」の表紙。やわらかな昼の光の中の、一筋の小道と道標、足あと。文字は入れない（題字はアプリ側で重ねる）。

### 4. ルート絵 `assets/ui-round3/pilgrimage/route-firstStep.webp`
- 1024×1536、WebP。
- 参考: `assets/ui-round3/pilgrimage/route-sanctuary.webp`。
- 内容: ルート選択画面のカード用。道標から小さな社へ続く、ごく短い道（鳥居は主役にしない）。
