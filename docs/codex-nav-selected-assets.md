# ナビバーの選択表示（4案の比較用アセット）（Codex依頼）

ナビバーで選択中のタブを分かりやすくするため、4案を試す。画像は4枚。
現状は、朱の小さな丸（`assets/ui-washi/home/nav-tab-active.webp`）と筆の下線だけで、分かりにくい。

## 共通ルール

- 場所: `assets/ui-washi/nav/`（新規フォルダ）。形式は透明な WebP。
- 背景は完全な透明（アルファ）。市松模様や透けた背景の焼き込みは禁止。
- 文字や記号は絵に入れない。アイコンと文字は、アプリ側で重ねる。
- 作風は `assets/ui-washi/` の既存素材（和紙、墨、朱）に合わせる。朱は既存の御朱印の朱（`docs/ARTWORK.md`）。
- 影は描き込まない（アプリ側で付ける）。
- 各ファイル 60KB 以下を目安に最適化する。
- 生成プロンプトは `docs/gacha-assets-prompts.md` の末尾ではなく、`docs/nav-assets-prompts.md` に記録する。
- コード（`src/`、`App.tsx`）は変更しない。素材と記録だけ。

## 素材

| ファイル | サイズ | 案 | 内容 |
|---|---|---|---|
| `nav-plate-vermilion.webp` | 192×176 | A | 朱色の板。タブ全体（アイコンと文字）の背景に敷く。角は少し丸く、縁は和紙を手でちぎったような、わずかな揺らぎ。朱のムラと、紙の繊維の質感。**中央は、白いアイコンと文字が読めるように、ほぼ均一な朱**。縁だけやや濃い |
| `nav-ema-selected.webp` | 176×200 | B | 絵馬の形の板。上が屋根のような五角形で、上端に小さな穴と朱の紐。板は明るい木の色（桐）に、朱の縁取り。**中央は、朱のアイコンが読める、明るく均一な木肌**。下に文字を出すため、板の下半分は使わない |
| `nav-brush-top.webp` | 256×40 | D | 横長の、朱の太い筆線。両端がかすれて細くなる。真っ直ぐに近いが、わずかに揺らぐ。ナビバーの上辺に、タブの幅だけ引く |
| `nav-underline-thick.webp` | 256×36 | C | 既存の筆の下線（`assets/ui-washi/common/underline-brush.webp`）より、太く長い朱の筆線。墨のかすれ付き。文字の下に引く |

## 確認

- 4枚とも、アルファ付きで、四隅が完全に透明であること。
- A、B は、白いアイコン（A）と朱のアイコン（B）を中央に重ねて、読めること。暗い色（`#302D25`）と、ナビバーの和紙の上（`#F2E8D2`）の両方で、輪郭が崩れないこと。
- 完了したら、ファイルとサイズをコミットメッセージに書く。
