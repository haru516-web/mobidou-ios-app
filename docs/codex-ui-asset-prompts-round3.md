# Codex 向け UI アセット 第3弾(キャラ以外の全面作り直し)

キャラクターを除く、アプリのすべての画像アセットと、いまコードで描いている UI 部品(ボタン、枠、アイコンなど)を、
第1弾・第2弾と同じ手ざわり(実物の和紙・墨・朱・木)で作り直します。

## 0. 進め方(最初に読む)

- **作業ブランチ**: `codex/ui-assets-round3`(用意済み。最新の `claude/ui-navigation-overhaul` から切ってあります)。
  ワークツリーは Codex が自分で作ってください。ブランチ名はそのまま使います。
- **コードは触らない。** 追加してよいのは `assets/ui-round3/` 配下の画像と、次の2つのファイルだけです。
  - `assets/ui-round3/MANIFEST.md`(ファイル、寸法、用途の一覧)
  - `assets/ui-round3/slices.json`(引き伸ばして使う部品の「端の固定幅」。下の「引き伸ばし部品」を参照)
- **既存の画像は消さない、上書きしない。** 置き換え候補は、同じファイル名で `assets/ui-round3/<分類>/` に作ります。
  差し替えは私がコード側で行います。
- 出力は WebP(品質90前後、アルファ維持)。原本 PNG は残さない。
- 分類ごと(A〜G)に1コミット。コミットメッセージに分類名を入れる。
- 生成のたびに、既存の画像・第1弾/第2弾の画像(`assets/ui-washi/`)を開いて、**紙・光・色味をそろえる**。

### 作り直しの対象外(触らない)

- キャラクター: `assets/mobies/` の全キャラ画像、動きのスプライト(actions / pull / reactions / prayer-v2 / pilgrimage-walk)、
  おみくじのキャラ画像(mobies/omikuji)
- 御朱印(`assets/goshuin/`)、ミニチュア(`assets/collection/keychains/`)
- ブランド画像: アプリアイコン、オープニングの紋章、筆文字のロゴ
- すでに第1弾・第2弾で作った `assets/ui-washi/`、`assets/pop-buttons/`

## 1. 共通スタイル指示(全プロンプトの冒頭に付ける)

```
アプリ「もびどう」の UI と背景。既存の和紙・御朱印・巡礼の世界観に合わせる。
- 素材は実物の和紙、麻布、木、墨、朱、金の細工。フラットな単色塗りと機械的な角丸矩形は禁止。
- 縁は手でちぎった耳(不規則で繊維が毛羽立つ)か、筆で引いたかすれ。直線・正円の縁を使わない。
- 光源は左上の柔らかい自然光。影は「物の実際の輪郭に沿った」薄い接地影のみを右下に落とす。
  箱型・均一ぼかしのドロップシャドウは禁止。影の指定がある物だけ焼き込む。
- 配色は生成り、淡い墨、朱(#A54E42 付近)、藍、若草の低彩度。
- 文字・数字・ロゴ・透かし・キャラクターを絵の中に描かない(指定があるものを除く)。
- 透過指定のものは完全な透過背景で、縁に白フチ・黒フチを出さない。
```

## 2. 引き伸ばし部品のルール(A 分類)

ボタン、枠、札、帯は画面ごとに大きさが違うので、私が「3分割」または「9分割」で引き伸ばして使います。

- **3分割(横だけ伸ばす)**: 左右の端を固定し、真ん中だけ伸ばす。真ん中(左右の端を除いた部分)は、
  どこを切っても同じに見える無地の紙にする(目立つ繊維、しみ、落款を置かない)。
- **9分割(縦横に伸ばす)**: 四隅を固定し、辺と中央を伸ばす。辺の部分も、伸ばして目立たない連続した縁にする。
  四隅の内側から中央までは無地。
- `slices.json` に、各画像の固定幅を原寸のピクセルで書く。例:
  `{ "ui/button-primary.webp": { "left": 150, "right": 150 }, "ui/card-frame.webp": { "left": 120, "right": 120, "top": 120, "bottom": 120 } }`
- 3分割・9分割の部品は、**指定の縦横比どおり**に、その形で描く(小さく描いて拡大しない)。
