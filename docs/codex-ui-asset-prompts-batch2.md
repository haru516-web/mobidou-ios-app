# Codex 向け UI アセット 追加分(第2弾)

第1弾の素材をアプリに組み込んでみて、**形(縦横比)が合わない部品**が分かりました。
画像を引き伸ばすと手ちぎりの縁が歪むので、実際の画面サイズに合わせた形で作り直してください。
作業場所とルールは第1弾と同じです(`docs/codex-ui-asset-prompts.md` の「作業ルール」「共通スタイル指示」「共通の合格条件」)。

- 作業場所: `D:/mobby/mobidou-assets`(ブランチ `codex/ui-washi-assets`)。すでに最新のコードをマージ済みにしてから渡します。
- 追加先: `assets/ui-washi/home/`(ホームの5枚)、`assets/ui-washi/walk/`(絵図)、`assets/ui-washi/settings/`(設定)
- 生成後は WebP(品質90前後、アルファ維持)に変換し、`assets/ui-washi/MANIFEST.md` に追記する。
- 影は第1弾と同じく、「実際の縁の形に沿った、右下に落ちる薄い接地影」だけを焼き込む。

## プロンプト

### 歩数カード(横長)

```
手ちぎり和紙の横長の札。plate-steps.webp(第1弾)と同じ紙と光で、縦横比だけを 2.5:1 にする。
中央は文字と数字を載せる無地の和紙面。縁の耳は不規則に毛羽立つ。
左端に小さな朱の筆の点を1つ。札の下端だけに輪郭に沿った薄い接地影。
```

### 御朱印カード・おみくじカード(縦長)

```
手ちぎり和紙の縦長の札(縦横比 0.64:1)。第1弾の plate-goshuin / plate-omikuji と同じ紙と光。
plate-portrait-goshuin: 中央上寄りに薄い朱の落款の地紋を透かす。落款そのものは描かない。
plate-portrait-omikuji: 縦に1本の折り目、右下に薄い藍のかすれ。
中央は無地。縁の耳は不規則に毛羽立つ。下端と右端に輪郭に沿った薄い接地影。
```

### 吹き出し(横長)

```
モビーが話す吹き出しとなる、手ちぎり和紙の横長の吹き出し。
本体は縦横比 約4:1 の細長い紙片の輪郭で、縁は不規則。角丸の楕円にしない。
下端から小さな和紙のしっぽが伸びる(left は左寄り、right は右寄り。しっぽの付け根は本体の下端から
全体の高さの20%の範囲に収める)。
中央は文字を1〜2行載せる無地。第1弾の bubble-left / bubble-right と同じ紙と光。
```

### 絵図のポップ

```
巡礼の地図(絵図)を載せる、広げた和紙の巻物。縦長(1024×1400)で、画面の幅いっぱいに広がる。
第1弾の index-popup(目次の掛け軸)と同じ素材感だが、目次より幅の広い形にする。
- 紙の本体は、画像の幅の 92%以上、高さの 88%以上を占める。左右と上下の透明な余白は各 4%以内。
- 上下に細い木の軸(巻き取り棒)、上の軸に麻紐。左右の縁は手ちぎり。
- 紙面の中央 80% は無地。ここに地図の絵と地点の印をアプリ側で載せる(地図の絵は描かない)。
- 縁に沿った薄い接地影だけを焼き込む。
```

### 設定画面の背景

```
設定画面の全面の背景となる、縦長(1170×2532)の和紙。不透明。透明部分なし。
- 生成りの和紙。繊維とわずかなムラ。上端から下端まで、同じ紙が続く。
- 上部 12% に、墨を薄くにじませた一筆の横帯(見出しの背後に敷く、ごく薄い灰)。
- 下部 18% に、遠くの山並みを墨の淡彩(ごく薄い灰青)でぼかして描く。主張しない。
- 中央 70% はほぼ無地。文字とカードを載せても読める明るさと低いコントラスト。
- 端に向かってごくわずかに暗くなる(紙の焼け)。角丸や枠線は描かない。
- 文字・数字・ロゴ・キャラクターは描かない。
```

## 共通の合格条件(追加)

1. 指定寸法どおりで、透明背景。縁に白フチ・黒フチがない。
2. 各画像の「紙の部分」が画像の端いっぱいに使われ、上下左右の透明な余白が 3% 以内。
3. 縦横比が指定と違わない(引き伸ばした画像ではなく、その形で描かれている)。
   settings-bg だけは不透明(透明部分がない)で、他はすべて透明背景。
4. 文字・数字・キャラクターがない。
