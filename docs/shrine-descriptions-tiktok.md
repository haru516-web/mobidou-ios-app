# もび道 全75地点 寺社解説集（TikTok投稿用）

もび道の巡礼13ルート・75地点（入門1地点＋12ルート74地点）を、1地点ずつ「どんな寺社か」「どんな人に刺さるか」が伝わるようにまとめた投稿ネタ帳。

## 使い方

- **世界観の注意**: すべて「もび道」の世界に実在する創作の寺社で、現実の寺社ではない。投稿には「もび道の世界の社」「アプリで巡れる」と一言入れ、実在の神社と誤認されないようにする。
- **被り対策**: 全地点で「ご利益の切り口」を変えている（縁切り・復活・睡眠・自信・断捨離など）。切り口が近い地点は、場所・仕掛け・景観の特徴で差をつけた。
- **構成**: 各地点は「フック（冒頭1行）」「解説」「特徴」「こんな人に」の4点。フックは動画の冒頭テロップ、解説はナレーション、特徴は映像の見せ場にそのまま使える。
- **出典**: 名称・読み・場所・建築・景観・問いは `docs/pilgrimage-v2-route-world.md` と `src/data/shrines.ts` に基づく。ご利益の言い回しと切り口は投稿用の脚色。
- **対象外**: 現行の12ルートに入っていない地点（保留中の門前宿場巡り12地点の一部、ルート未所属の地点）は含めていない。
