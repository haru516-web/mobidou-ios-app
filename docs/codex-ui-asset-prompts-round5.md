# Codex 向け UI アセット 第5弾(ガチャの導線と購入タブ)

ガチャを下部ナビに固定し、ガチャ画面に「ひく／購入」のタブを付けたことで、**足りなくなった画像**です。
いまは仮の表示(ナビは贈り物アイコンの流用、タブと商品カードはコードで描いた暗い角丸の箱)になっていて、
アプリの和紙・漆の世界観と合っていません。これらを画像に置き換えます。

作業の進め方と共通スタイルは、`docs/codex-ui-asset-prompts-round3.md` の「0. 進め方」「1. 共通スタイル指示」「2. 引き伸ばし部品のルール」と同じです。

- **作業ブランチ**: `codex/ui-assets-round5`(用意済み。最新の `claude/ui-navigation-overhaul` から切ってあります)。
  ワークツリーは Codex が自分で作ってください。
- **コードは触らない。** 追加してよいのは `assets/ui-round5/` 配下の画像と、`assets/ui-round5/MANIFEST.md`(ファイル、寸法、用途の一覧)、
  引き伸ばす部品の `assets/ui-round5/slices.json`(端の固定幅)だけです。差し替えは私がコード側で行います。
- 出力は WebP(品質90前後、アルファ維持)。原本 PNG は残さない。
- 分類ごと(N・T・S)に1コミット。
- 生成のたびに、既存の画像(`assets/ui-round3/icons/`、`assets/ui-washi/home/nav-bar.webp`、`assets/gacha/`)を開いて、**線の太さ・紙・漆・色味をそろえる**。
- 画像の中に、文字・数字・ロゴを描かない(文字はアプリ側で重ねる)。

## 画面の背景(重ねる先)

- ナビ: 和紙の帯(`assets/ui-washi/home/nav-bar.webp`)。アイコンは筆で描いたような一色の線画。選択中は朱の印が背後に出る。
- ガチャ画面: 夜明け前の縁側の写実的な背景(`assets/gacha/stage-bg.webp`)。タブ・カードはその上に重なる。明るい板張りと青い空の両方に載るので、**どちらの上でも読める**こと。

## 分類 N: ナビのアイコン

### N-1 ガチャのアイコン `assets/ui-round5/icons/icon-gacha.webp`(191×191、透過)

既存の `assets/ui-round3/icons/icon-home.webp`、`icon-book.webp`、`icon-footsteps.webp`、`icon-collection.webp` と**同じ寸法・同じ線の太さ・同じ色**にする。まず既存のこの4枚を開いて確認すること。

```
ナビの小さなアイコン。上の4枚と同じ手描きの墨の線画で、ガチャの箱を描く。
- 題材: 正面を向いた小さな漆の箱。前板が少し持ち上がっていて、隙間から細い光が一筋出ている。上から細い紐が1本垂れて、先に小さな房がある。
- 1色(濃い墨、既存のアイコンと同じ色)の線画。塗りは使わない。ただし光の筋だけ、ごく薄い金を1か所だけ使ってよい。
- 22px 程度に縮小しても、箱と紐の形が分かること。細かい装飾を入れない。
- 透過背景。縁に白フチを出さない。
```

## 分類 T: ガチャ画面のタブ

### T-1 タブの板 `assets/ui-round5/tabs/tab-on.webp` と `tab-off.webp`(各 480×128、引き伸ばし部品)

横に引き伸ばして使う(左右 56px を固定、中央を伸ばす)。幅が約 84〜140px の範囲で使う。

```
ガチャ画面のタブ「ひく」「購入」の背景板。2枚組。
- tab-on(選ばれている側): 生成りの和紙を手で切った小さな帯。縁は不規則で繊維が毛羽立つ。ごく薄い朱の縁取りを一筋。
- tab-off(選ばれていない側): 深い焦げ茶の漆の板。縁は同じく手切りの不規則さ。金の細い縁取りを一筋、かすれさせる。
- どちらも、明るい板張りの上と、青い夜明けの空の上の両方で、輪郭がはっきり見えること。
- 左右の端(固定部)に模様や飾りを置かない。中央(伸びる部分)は無地に近くする。文字は描かない。
- 透過背景。縁に白フチ・黒フチを出さない。接地影は右下に薄く、物の輪郭に沿ってだけ。
```

## 分類 S: 購入タブの部品

### S-1 商品カードの板 `assets/ui-round5/shop/card-plate.webp`(1000×300、引き伸ばし部品)

```
商品を並べるカードの背景板。左右 80px、上下 60px を固定して引き伸ばす(9スライス)。
- 深い焦げ茶の漆を塗った横長の板。縁は金の細い蒔絵の線を一周させ、四隅だけ小さな金の留め金具を付ける。
- 中央は無地に近い、静かな漆の艶。文字が載るので、模様は薄く、コントラストは低く。
- 明るい板張りの上でも沈まず、輪郭が見えること。
- 透過背景。接地影は物の輪郭に沿って薄く。文字は描かない。
```

### S-2 見出しの札 `assets/ui-round5/shop/heading-plate.webp`(480×96、引き伸ばし部品、左右 40px 固定)

```
「ご縁を迎える」「月ごとのプラン」の見出しの下に敷く、細い札。
- 生成りの和紙の細い短冊。左端に小さな朱の印を一つ。縁は手切りで不規則。
- 文字を載せる中央は無地。文字は描かない。透過背景。
```

### S-3 商品の絵 4枚 `assets/ui-round5/shop/product-*.webp`(各 256×256、透過)

カードの左に置く小さな絵。**4枚で同じ筆づかい・同じ光**にそろえる。文字・数字・金額を描かない。

```
product-pull1.webp : 漆の小箱が1つ。前板が少し上がり、細い光が一筋。紐が1本。
product-pull5.webp : 同じ漆の小箱が5つ、扇のように重なって並ぶ。手前の1つだけ前板が上がり、光が出ている。
product-plan-light.webp : 小さな月と、その下に朱の組紐が1本。静かで控えめな佇まい。
product-plan-plus.webp : 大きな月と、その下に朱の組紐が3本、金の小さな星が数粒。ライトより華やか。
```
