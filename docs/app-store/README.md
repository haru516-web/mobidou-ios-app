# もび道 — App Store用スクリーンショット

日本語 / iPhone 6.9インチ枠 / 1320 × 2868 px / RGB PNG（透過なし）

## 納品ファイル

`iphone-6.9/` の5枚を番号順で掲載する構成です。

1. `01-home.png` — いつもの散歩が、小さな旅になる。
2. `02-book.png` — 歩いた日々が、御朱印帳になる。全42種のご縁を収録。
3. `03-story.png` — ひらくたび、ご縁に出会う。
4. `04-walk.png` — あと少し先に、新しい楽しみ。
5. `05-mobbies.png` — 18体のモビー。今日は、誰と歩く？

`overview.png` は一覧確認用です。ストアへアップロードする画像には含めません。
`preview.html` は拡大確認用、`raw/01-*.png`〜`raw/05-*.png` は装飾前の画面です。

## 撮影について

- 2026年9月10日制作。ローカルのもび道Web版を440 × 956 CSS px、3倍解像度で撮影しました。
- iPhone実機やiOSシミュレーターで撮影した画像ではありません。提出前には提出対象のiOSビルドと表示が一致するか確認してください。
- 撮影専用の独立ブラウザにサンプル保存データを設定しました。歩数3,280歩、御朱印2枚、モビ坊とのふれあい24回。実ユーザーの歩行記録ではありません。
- ホーム、御朱印帳、御朱印詳細、おでかけ、モビー選択をアプリの操作で開きました。機能や画面の文字は合成・置換していません。
- ネイティブ歩数連携はWebでは利用できないため、画面には「未接続」や歩数連携ボタンが表示されています。
- アプリのコードは変更していません。UI外の紹介文・背景・枠をHTML/CSSで制作しました。
- 掲載している社・御朱印は、アプリ内の架空のものです。

## サイズ根拠

Apple公式の[スクリーンショット仕様](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/)を2026年9月9日に確認。6.9インチ枠の縦1320 × 2868 pxと、透過なしPNGの仕様に合わせています。

## 再作成

ローカルアプリをポート8083で起動して、リポジトリルートで実行します。

```powershell
node docs/app-store/capture.cjs
node docs/app-store/render.cjs
```

スクリプトはこの環境の同梱PlaywrightとMicrosoft Edgeを使用します。他の環境ではrequire先とブラウザー設定を調整してください。撮影日は実行日になります。
