## 状況別の共通セリフ

状況別は会話時に使用。重なるときは「結願直後 → 御朱印直後 → 久しぶり → 残り歩数 → 好感度 → 時間帯」の順。時間帯などは端末の状況を呼び出し元が渡す。復帰を責める文面は入れない。

| 状況 | 文案 |
|---|---|
| 朝（5〜10時） | おはよう。今日の一歩、ゆっくり始めよう。 / 朝の空気、どんな感じかな。 |
| 昼（11〜16時） | こんにちは。お昼のひと息、いっしょにしよう。 / 今の空、少し眺めてみようか。 |
| 夕方（17〜19時） | 今日もここまで、おつかれさま。 / 夕方の道、帰りはのんびりね。 |
| 夜（20〜4時） | こんばんは。今夜はゆっくり休もうね。 / 今日の小さな発見、ひとつ聞かせて。 |
| 7日以上ぶり | おかえり。会えてうれしいよ。 / 久しぶりだね。また、きみのペースで歩こう。 |
| 御朱印直後 | 新しい御朱印、いっしょに眺めよう。 / 今日の一歩が、旅の証になったね。 |
| 結願直後 | ここまで歩いたね。いっしょに来られてうれしい。 / 旅の証が増えたね。今日は、ゆっくり余韻を楽しもう。 |
| 次の地点まで1〜100歩 | 次の場所まで、あと少し。急がず行こう。 / もうすぐだね。疲れていたら、続きはまた今度でも。 |
| 好感度：出会いたて | きみの好きな道、少しずつ教えてね。 / これから、いっしょの思い出を増やそう。 |
| 好感度：なかよし | きみとの寄り道、楽しみになってきたよ。 / 今日も、いつもの場所でひと息つこう。 |
| 好感度：相棒 | きみの歩幅、すっかりおなじみだね。 / 歩く日も休む日も、きみと過ごすのが好き。 |

## おみくじ追加4種（合計25種、各ランク5種）

配列長が変わるため、同じ日付の新規選択結果が従来と変わることはある。
画像はキャラIDに対応するため、fortune IDの追加による画像変更は不要。

## 状況受け渡し案

`reactionLine(id, kind, count, context?)`。contextは `hour?: number`, `daysSinceLastOpen?: number`, `justReceivedGoshuin?: boolean`, `justCompletedPilgrimage?: boolean`, `remainingSteps?: number`, `affinityStage?: 'new' | 'friendly' | 'partner'`。
段階の数値しきい値は既存の好感度仕様を呼び出し元が使う。API内で保存データや時刻を読み書きしない。
`PullableCompanion` に任意の `reactionContext` propを追加し、既存の呼び出しへ第4引数として渡す。
App.tsx側は既存の時刻・最終起動・授与イベント・残り歩数・好感度から作ったcontextを同propへ渡す。直後フラグの有効期間はApp側で管理し、過去の授与が毎回再生されないようにする。
今回App.tsxは変更しないため、App側の接続までは状況別文面は通常操作に出ない。
