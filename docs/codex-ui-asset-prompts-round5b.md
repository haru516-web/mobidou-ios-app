## 1. 共通スタイル指示(各プロンプトの冒頭に付ける)

```
アプリ「もびどう」の UI。既存の和紙・御朱印・巡礼の世界観に合わせる。
```

## 2. 直したい点

### 2-1. 商品イラスト `product-pull1` と `product-pull5`(256×256)

**問題**

- 暗い赤茶の漆の木箱を、暗い赤茶の漆の板(`card-plate.webp`)の上に載せるので、箱が板に溶けて見えにくい。
- 絵の質感が、光沢のある 3D レンダリング風。`product-plan-light` と `product-plan-plus`(手描き風で平らな絵)や、
  アプリ全体の手描きの手ざわりと合っていない。
- `product-pull5` は箱が5つ重なっていて、小さく表示すると何の絵か分からなくなる。

**直し方**

- 暗い板の上で目立つように、**明るい色**にする。生成りの白木の箱、または朱塗りの箱。金の飾り金具と、紅い組みひもの房。
  輪郭に、**墨の細い線**を入れる(明るい箱に暗い輪郭で締める)。
- 手描きの水彩と墨の質感。艶やハイライトは、筆で白を抜く程度にとどめる。
- 同じ**ひとつの箱の絵**で `pull1` と `pull5` をそろえる。
  - `pull1`: 箱ひとつ。真ん中に組みひもの房がひとつ下がる。
  - `pull5`: 同じ箱を**3つだけ**、前に1つ、後ろに2つ並べる。数が多いと小さな画面で潰れるので、
    「5」は数では見せない。箱の飾りひもの房を**5本**に増やして、5回分であることを示す。
- 箱の輪郭が、暗い背景(#3A1A12 付近)に対して十分な明るさの差を持つこと。256×256 の中央に収め、四辺に 20px 以上の余白を残す。
- 出力: `assets/ui-round5b/shop/product-pull1.webp`、`assets/ui-round5b/shop/product-pull5.webp`。

### 2-2. ガチャのナビアイコン `icon-gacha`(191×191)

**問題**

- 絵の一部に、金色の光の差し込み(箱の隙間の光)が入っている。ナビでは、他のアイコンと同じ灰色にそろえるため、
  アプリ側で絵全体を単色に染める(色の置き換え)。そのため金色の光が失われて見えない。

**直し方**

- 金色の光を**外した**、**墨一色**の線画にする。絵はいまの構図(吊るされた箱と房)のまま。
  線の太さと筆のかすれは、いまのままで構いません。
- 色は黒に近い濃い墨一色。透過背景。他の色(金、朱)を入れない。
- 出力: `assets/ui-round5b/icons/icon-gacha-ink.webp`(191×191)。
