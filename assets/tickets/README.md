# Mobidou ticket bases

Two generated, text-free portrait ticket bases for the collection pass cards.

| Asset | Size | Intended overlay |
| --- | --- | --- |
| `ticket-cover-change-v1.png` | 1024 × 1536 px | 御朱印帳表紙着せ替え券 |
| `ticket-keychain-drop-v1.png` | 1024 × 1536 px | ミニチュアキーホルダードロップ券 |

Both PNGs have transparent outer pixels, an aged ivory washi center, physical top/bottom notches, and a lower perforation line. The quiet center is intentionally reserved for React Native text and count controls; no lettering, numerals, logos, mascots, or watermarks are baked into the images.

Generated with the built-in `image_gen` tool. The provided `pass-ex.png` was used as a visual/style reference only.
