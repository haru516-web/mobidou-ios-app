# Mobidou pass artwork

The active pass images are `ticket-cover-change-v2.png` and `ticket-keychain-drop-v2.png` (1024 × 1536 PNG). They are illustrated washi travel coupons with the fixed Japanese names and captions baked into the pixels. Live balances are rendered by the app below each image.

The text-free ImageGen artwork is preserved in `sources-v2/`. Run `scripts/build-ticket-v2.py` with the bundled Python runtime and Pillow to rebuild the final PNGs after editing the fixed copy. The script uses the project's Shippori Mincho fonts.

The older `*-v1.png` tickets remain as unused source history.
